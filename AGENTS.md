# Контракт агента (Codex и любые другие агенты)

В этой папке работает команда из трёх чатов. Роль определяется **первым сообщением сессии**. Схема всего пути: `docs/SCENARIO.md`.

1. Сначала прочитай `.claude/skills/onai-team/SKILL.md`: роли, файлы-передачи, создание сессий, ключи, общие запреты.
2. Определи роль по первому сообщению и прочитай навык этой роли целиком:
   - ссылка на репозиторий или роли нет: **Монтажёр**, `.claude/skills/onai-montage/SKILL.md`, начни с раздела 1 «Первые 5 минут»;
   - «Ты Скриптолог этой папки…»: **Скриптолог**, `.claude/skills/onai-scriptolog/SKILL.md`, начни с раздела 1;
   - «Ты Instagram-автоматизатор этой папки…»: **Instagram-автоматизатор**, `.claude/skills/onai-automator/SKILL.md`, начни с раздела 1.
3. Навыки двух других ролей не читай: у каждой роли своя зона.
4. Справочники роли лежат рядом с её навыком (`reference/`, `references/`). `patterns/`, `docs/` и код образцов это справка: при расхождении прав навык.
5. Нет возможности создавать сессии карточками (это умеет Claude Desktop): отдай владельцу `docs/guides/claude-desktop-sessions.md` и тексты из `team/prompts/`.

Запреты без исключений:
- монтаж только на Remotion; финальный рендер только после одобрения кадров К001… и черновика 720p;
- не выдумывать факты, цифры, интерфейсы и логотипы;
- зрителю не диктовать команды терминала, только «отдай ссылку Claude, он сам установит»;
- ключи, токены и пароли не писать в чат, файлы репозитория, коммиты и отчёты;
- не коммитить записи владельца и данные клиентов, не пушить и не публиковать без его прямого слова.
