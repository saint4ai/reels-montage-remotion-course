# Контракт агента (Codex и любые другие агенты)

Этот репозиторий ведётся **одним навыком**: `.claude/skills/onai-montage/SKILL.md`.

1. Первое действие в любой сессии: прочитать `SKILL.md` целиком и выполнить его раздел 1 «Первые 5 минут»:
   `npm install` при необходимости, `npm run doctor`, сверка карты репозитория, онбординг и интервью владельцу.
2. Работать только по навыку и его справочникам `.claude/skills/onai-montage/reference/01…05`, `pitfalls.md`.
   `patterns/`, `docs/`, код образцов это справка; при любом расхождении прав навык.
3. Шаги курса 1.1–1.5 идут по порядку, каждый заканчивается воротами: показать владельцу и дождаться ответа.

Запреты без исключений:
- монтаж только на Remotion;
- финальный рендер только после одобрения кадров К001… и черновика 720p;
- не выдумывать факты, цифры, интерфейсы и логотипы;
- зрителю не диктовать команды терминала, только «отдай ссылку Claude, он сам установит»;
- не коммитить записи владельца и секреты, не пушить и не публиковать без его слова.
