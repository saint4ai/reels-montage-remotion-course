# Проверка перед выдачей

Полный список для агента: раздел 5 навыка `.claude/skills/onai-montage/SKILL.md` и раздел 7 справочника
`reference/04-build.md`. Коротко:

- `npm run check`, `npm run qa -- <id>` (FIT PASS), `npm run qa -- FitTest` (обязан FIT FAIL).
- Лист кадров К001… каждые 2 с показан владельцу целиком и одобрен; стыки проверены по 6–8 кадров.
- Кадр 0 не пустой, первые 3 с одна огромная фраза, текст не на лице, голова не обрезана.
- Черновик 720p одобрен. Финал: размер, fps, битрейт замерены по файлу, −14 LUFS, чёрных кадров нет.
