# Zernio: один вход для Instagram, WhatsApp и Telegram

Сверено с документацией Zernio на 10.10.2026. Надписи на кнопках в панели могут отличаться: ориентируйся на смысл, а если не совпало, скажи агенту, что видишь на экране.

## Что это и зачем

Zernio (zernio.com) это сервис-посредник. Ты подключаешь к нему свои аккаунты один раз. Дальше ассистент читает входящие сообщения и комментарии и отвечает на них через один API (программный вход), а не через три разных.

Входящее сообщение приходит на адрес твоего сервера (вебхук). Ассистент думает и отвечает обратно через Zernio.

## Что понадобится

- Электронная почта для регистрации в Zernio.
- Instagram-аккаунт типа «Бизнес» (Business) или «Автор» (Creator). Личный аккаунт через API подключить нельзя.
- Для WhatsApp: аккаунт Meta Business (business.facebook.com) и номер телефона, который можно привязать к WhatsApp Business. Личный WhatsApp подключить нельзя.
- Для Telegram: твой канал или группа, где ты администратор.
- Сервер с адресом `https://...` для вебхуков. Как его получить, написано в `server-vps.md`.
- Claude Code (см. `claude-desktop.md`).

## Шаги

### 1. Регистрация

1. Открой https://zernio.com.
2. Создай аккаунт или войди (в документации: «create an account or log in»). Способ входа выбери любой из предложенных.
3. Для первых двух аккаунтов карта не нужна (например, Instagram и WhatsApp). Третий аккаунт без карты Zernio не подключит: ответ 402 с причиной `free_tier_exceeded` (бесплатный лимит профиля исчерпан, карты нет). Карту добавляют на странице https://zernio.com/dashboard?tab=billing. См. таблицу ошибок ниже.

### 2. API-ключ

1. Войди в Zernio и открой https://zernio.com/dashboard/api-keys.
2. Нажми «Create API key» (создать API-ключ).
3. Введи имя (name), например `assistant`. Срок действия (expiresIn, в днях) можно не задавать.
4. Выбери доступ (scope): `full` (все профили, по умолчанию) или `profiles` (только выбранные профили). Для одного бизнеса хватит `full`.
5. Выбери права (permission): **`read-write`** (чтение и запись, по умолчанию). Вариант `read` пускает только запросы чтения (GET). Ассистенту, который отвечает людям, этого мало. Отдельного пункта «только запись» в документации нет.
6. Группы ресурсов (resource groups): ничего не отключай. Ключ с любой отключённой группой получает приставку `zrk_` и теряет часть доступа. Для ассистента нужны минимум группа `messages` (входящие, ответы) и группа `webhooks`.
7. Скопируй ключ сразу. Zernio хранит только хеш и больше его не покажет. Ключ выглядит так: `sk_` и 64 символа (всего 67).

Подписи полей взяты из описания API, на экране они могут отличаться чуть-чуть. Проверь на месте: если не совпало, скажи агенту, что видишь.

Как ключ потом отправляется: в заголовке `Authorization: Bearer <ключ>`. Адрес API: `https://zernio.com/api/v1`. Это делает агент, тебе руками ничего писать не нужно.

### 3. Подключить Instagram

Условия (страница docs.zernio.com/platforms/instagram):

- Нужен аккаунт «Бизнес» или «Автор». Как переключить аккаунт на профессиональный, в документации Zernio нет. Это делается в настройках самого Instagram.
- **Страница Facebook не нужна**, если подключаешь способом по умолчанию (Instagram Login, вход через Instagram). Страница Facebook нужна только при входе через Facebook (Facebook Login). Он обязателен для рекламы, платного партнёрского ярлыка, музыки из каталога и лайков комментариев. Ассистенту директа и комментариев он не нужен.
- Директ и комментарии работают одинаково при обоих способах входа.

Шаги в панели (по статьям блога Zernio, подписи кнопок проверь на месте):

1. В боковом меню открой «Connections» (подключения).
2. Выбери профиль, в который подключаешь аккаунт. В новом аккаунте уже есть профиль `Default`.
3. Нажми кнопку подключения («Connect account» или «New Connection», подписи в разных статьях разные) и выбери Instagram.
4. Выбери способ входа: напрямую через Instagram (проще) или через Facebook.
5. Войди в Instagram и разреши доступ. Для ассистента нужны разрешения на сообщения (messaging) и комментарии (comments).
6. Вернись в Zernio. Аккаунт должен появиться в списке.

Второй путь: попроси агента подключить через API. Он вызывает `GET /v1/connect/instagram` и даёт тебе ссылку для входа. По этой ссылке авторизуешься ты сам.

Что полезно знать:

- Ответить в директе можно в течение 24 часов после сообщения человека. Для сообщений позже в документации указан тег `HUMAN_AGENT`.
- Запросы от тех, на кого ты не подписан, лежат в отдельной папке. После ответа диалог переходит во «Входящие».
- Приватный ответ на комментарий можно отправить один раз и только в течение 7 дней.
- При подключении Zernio подтягивает старую переписку (до 500 диалогов). Если её нет, включи доступ к сообщениям в настройках Instagram в разделе «Connected tools» (подключённые инструменты) и подключи аккаунт заново.
- Если пришла ошибка «Instagram access token expired» (срок доступа истёк), переподключи аккаунт. Об этом заранее предупреждает событие `account.disconnected`.

### 4. Подключить WhatsApp

Страницы: docs.zernio.com/platforms/whatsapp и /platforms/whatsapp/connection.

1. Нужен аккаунт Meta Business (business.facebook.com). Внутри него нужен аккаунт WhatsApp Business (WABA). Если его нет, мастер подключения создаст его.
2. Нужен хотя бы один номер, привязанный к WABA.
3. Выбери режим:
   - **Coexistence** (совместная работа) по умолчанию. Номер остаётся в приложении WhatsApp Business на телефоне, а ты сканируешь QR-код. Минусы: не больше 20 сообщений в секунду, не работают группы через API и звонки. Номер уже должен быть активен в приложении **WhatsApp Business**. Обычный WhatsApp не подходит.
   - **Только Cloud API** (параметр `onboarding=api`): нужен для номеров, купленных в Zernio, и для групп или звонков. QR-кода нет.
4. Попроси агента вызвать `GET /v1/connect/whatsapp`. Он даст ссылку (`authUrl`). Открой её, войди в Meta, выбери или создай WABA, выбери номер. В панели Zernio путь тот же: «Connections», затем WhatsApp. Названия кнопок Meta могут отличаться, иди по смыслу.
5. После успеха ты вернёшься на страницу Zernio, а у аккаунта появится `accountId`.

Ограничения:

- Вне 24 часов после сообщения клиента можно слать только заранее одобренные шаблоны.
- Новый номер стартует с 250 разных получателей в день. Потом Meta поднимает лимит.
- Комментариев в WhatsApp нет.
- За рассылку шаблонов отдельно берёт Meta. Zernio и Meta выставляют счета отдельно.
- Для купленных в Zernio номеров в регулируемых странах нужна анкета (KYC), активация занимает обычно от 1 до 3 рабочих дней.

### 5. Подключить Telegram

Страница docs.zernio.com/platforms/telegram.

Zernio работает через **собственного бота Zernio** `@ZernioScheduleBot`. Токен от BotFather для этого не нужен. Подключается канал или группа, где ты администратор.

1. Попроси агента вызвать `GET /v1/connect/telegram` для твоего профиля. Он вернёт код вида `ZRN-ABC123`. Код живёт 15 минут.
2. В Telegram добавь `@ZernioScheduleBot` в канал администратором с правом «Post Messages» (публикация сообщений). В группу добавь его администратором.
3. Открой личный чат с `@ZernioScheduleBot` и отправь код и имя канала: `ZRN-ABC123 @твой_канал`. Если канал приватный и имени нет, перешли боту любое сообщение из канала вместе с кодом.
4. Агент опрашивает Zernio, пока статус не станет `connected`. Если код истёк (статус `expired`), запроси новый.

Что работает: личные сообщения, которые люди пишут боту, приходят во «Входящие» и в событие `message.received`. Чего нет: комментариев, аналитики, опросов.

Важно: в документации Zernio нет способа подключить к нему **своего** бота из BotFather (проверь на месте). Для заявок тебе нужен свой бот, он описан в `telegram-bot.md`. Это отдельная вещь.

### 6. Вебхуки: как ассистент узнаёт о новых сообщениях

Страницы: docs.zernio.com/webhooks, /webhooks/create-webhook-settings, /webhooks/test-webhook.

1. Открой https://zernio.com/dashboard/webhooks (или попроси агента вызвать `POST /v1/webhooks/settings`).
2. Заполни поля:
   - `name`: любое имя, от 1 до 50 символов;
   - `url`: адрес твоего сервера, например `https://203-0-113-10.sslip.io/webhooks/zernio`;
   - `events`: список событий, минимум одно. Для ассистента: **`message.received`** (входящее сообщение: Instagram, WhatsApp, Telegram) и **`comment.received`** (новый комментарий в Instagram);
   - `secret`: секрет подписи. Его придумываешь **ты**, Zernio сам не создаёт. Это значит: пусть агент сгенерирует длинную случайную строку, положит её в `.env` на сервере и передаст в Zernio. Тебе её видеть не нужно.
3. Нажми кнопку теста в панели (или агент вызывает `POST /v1/webhooks/test`). Придёт тестовое событие `webhook.test`.

Как проверяется подпись. Каждый запрос от Zernio содержит заголовок `X-Zernio-Signature`. Это HMAC-SHA256 от **сырого тела запроса** с твоим секретом, в виде строчных шестнадцатеричных символов. Если подпись не совпала, запрос обрабатывать нельзя.

Правила доставки:

- Ответ `2xx` должен прийти в течение 5 секунд. Поэтому сервер сначала отвечает «принято», а думает потом.
- Если ответа нет, Zernio повторяет доставку до 7 раз (задержки растут: 10 секунд, 1 мин 40 с, 16 мин 40 с, 2 ч 46 мин, потом по 24 часа).
- Доставка «минимум один раз», значит, одно событие может прийти дважды. Дубли отсеивай по заголовку `X-Zernio-Event-Id` (он же поле `id`).
- Если 3 дня подряд ничего не доставляется (и накопилось много сбоев), адрес могут отключить. Следи за журналом доставок в панели.
- Максимум 50 адресов на пользователя.

Что внутри события `message.received` (верхний уровень): `id`, `event`, `message` (текст, вложения, отправитель), `conversation` (в нём `id` диалога, нужен для ответа), `account` (`accountId`, `profileId`), `metadata`, `timestamp`. В `comment.received`: `comment`, `post`, `account`. Полные примеры JSON смотри в файле https://docs.zernio.com/llms-full.txt или в OpenAPI.

**Нужен ли HTTPS.** В словаре Zernio (Glossary) сказано, что адрес вебхука это «HTTPS URL». На странице создания вебхука прямого требования нет, а в примере стоит `http://example.com`. Делай адрес с HTTPS, это надёжнее. Как, написано в `server-vps.md`.

### 7. Подключить Zernio к Claude Code как MCP

MCP это способ дать агенту готовые «инструменты» сервиса. С Zernio-MCP агент сам смотрит список аккаунтов, читает диалоги и так далее. Адрес актуален на 10.10.2026: `https://mcp.zernio.com/mcp`.

**Если у тебя установлена команда `claude` (Claude Code в терминале):**

1. Выполни:
   ```
   claude mcp add --transport http zernio https://mcp.zernio.com/mcp
   ```
   Заголовок `Authorization` добавлять не нужно: вход идёт через браузер (OAuth 2.1).
2. Запусти Claude Code и введи `/mcp`. Выбери `zernio` и подтверди вход в браузере своим аккаунтом Zernio. Страница Zernio пишет это как `claude /mcp`. По документации Claude Code команда `/mcp` вводится внутри сессии.
3. Проверка: снова `/mcp`. У `zernio` должен стоять статус «connected». Потом попроси: «Покажи мои подключённые аккаунты в Zernio». Сработает инструмент `accounts_list`.

**Если ты работаешь только в приложении Claude Desktop (вкладка Code).** В приложение уже встроен Claude Code, но отдельной команды `claude` в терминале может не быть. Тогда есть два пути из документации Claude Code:

- Положи в папку проекта файл `.mcp.json`:
  ```json
  {
    "mcpServers": {
      "zernio": {
        "type": "http",
        "url": "https://mcp.zernio.com/mcp"
      }
    }
  }
  ```
  Потом в сессии введи `/mcp` и войди через браузер. Claude Code спросит разрешение на сервер из проекта, согласись.
- Либо в Claude Desktop: «Customize» → «Connectors» → «+ Add» → «Add custom connector», введи имя и этот же адрес. Проверь на месте, работает ли такой коннектор во вкладке Code. Если нет, используй файл `.mcp.json` выше.

Что ещё важно:

- Серверу доступно около 496 инструментов (все методы API). Claude Code показывает около 50, остальные находит через `search_tools` и запускает через `call_tool`.
- Среди них есть опасные: публикация и удаление. Проси агента сначала показывать, что он собирается сделать.
- Доступ можно отозвать: в Zernio есть раздел подключённых приложений, где виден список OAuth-клиентов (ассистентов) и их можно отозвать. Название раздела в панели может отличаться: ищи слова «подключённые приложения».
- Если вход не проходит, ошибка 401: удали сервер и добавь заново, чтобы вход через браузер запустился снова. После правки настроек полностью перезапусти программу.
- Для сред без браузера можно использовать ключ API в заголовке `Authorization: Bearer <ключ>`. Новичку это не нужно.
- Удобный файл для агента: https://docs.zernio.com/llms-full.txt (вся документация одним файлом, около 2,3 млн символов). Агенту лучше читать только нужные разделы.
- Страница https://zernio.com/claude написана как инструкция для ИИ-агента. Агент использует её только как справку: входить в аккаунты и принимать доступ он начинает после твоего подтверждения.

### 8. Публикация роликов: Instagram, TikTok, YouTube Shorts

Zernio не только отвечает на сообщения, он ещё выкладывает ролики. **Это платно:** TikTok и YouTube станут у тебя третьим и следующим аккаунтами Zernio, то есть по 6 долларов в месяц за каждый (первые два аккаунта бесплатны, например Instagram и WhatsApp; цены в разделе «Сколько это стоит»). Это работает только после слова «выкладывай» и только когда ассистент уже прошёл живую проверку (правило курса: `docs/SCENARIO.md`). Агент делает это через API или через MCP из шага 7. Главное для тебя:

- **Файл.** Zernio берёт видео по публичной ссылке без входа. Ссылки OneDrive, Google Drive, Dropbox и iCloud не годятся, поэтому агент сначала загружает файл в Zernio (`POST /v1/media/presign`, ссылка действует час). Через MCP-инструмент `posts_create` локальные файлы не принимаются, только ссылки.
- **Ключ.** Тот же ключ Zernio из `assistant/.env`, без отключённых групп ресурсов. Ключ в чат не вставляется.
- **Instagram.** Ролик выходит пробным рилсом (`trialParams`): его сначала показывают тем, кто на тебя не подписан. К подписчикам его переводишь ты сам в приложении Instagram, это режим `MANUAL`, он включён по умолчанию. Режим `SS_PERFORMANCE` (Instagram сам делится с подписчиками по просмотрам первых 72 часов) включается только по твоему слову. Лимиты Reels по Zernio: MP4 или MOV, до 300 МБ, 3–90 секунд, 9:16.
- **TikTok.** Агент подтверждает настройки публикации (видимость, комментарии, дуэты) только после твоего «выкладывай» на показанные подпись и настройки. Видео до 10 минут, 9:16. Закрытую публикацию или черновик в TikTok ты делаешь в приложении сам, агент их не создаёт.
- **YouTube Shorts.** Отдельного режима нет: вертикальное видео до 3 минут становится Shorts. Заголовок до 100 знаков.
- **Метка «создано ИИ»** ставится, если фон, предметы или голос сгенерированы и выглядят как настоящие (`higgsfield-talking-offer.md`).
- **Проверка.** Ответ «создано» ещё не значит «вышло». Агент смотрит статус поста и ссылку на каждой площадке и показывает тебе ссылки.
- Подробные параметры, порядок действий и время выкладки: `.claude/skills/onai-montage/reference/05-series-publish.md` и `docs/guides/best-time.md`.

## Сколько это стоит

Тарифных планов нет. Платишь за каждый подключённый аккаунт (соцсеть или мессенджер) в месяц. Все возможности включены в каждый аккаунт.

| Подключённые аккаунты | Цена |
|---|---|
| 1 и 2 | бесплатно, карта не нужна |
| с 3 по 10 | 6 долларов за каждый в месяц |
| с 11 по 100 | 3 доллара за каждый |
| со 101 | 1 доллар за каждый |

- Instagram + WhatsApp + Telegram это 3 аккаунта: два бесплатно и третий за 6 долларов в месяц (если считать по таблице).
- **Если выкладывать ролики через Zernio в TikTok и YouTube,** каждая такая площадка тоже аккаунт Zernio. Первые два аккаунта бесплатны (например, Instagram и WhatsApp), поэтому TikTok станет третьим, а YouTube четвёртым: по 6 долларов в месяц за каждый, то есть 12 долларов в месяц за оба. Если подключить только Instagram и TikTok, платить не придётся, а третий аккаунт (например, YouTube) уже платный. Прикинь расходы до подключения.
- Посты: без ограничений. Входящие сообщения: бесплатно.
- Исходящие сообщения (ответы в директе и других мессенджерах): первые 10 000 в месяц бесплатно, дальше 0,0001 доллара за сообщение, то есть 1 доллар за 10 000. Учёт идёт с 1 октября 2026. Без карты отправка после 10 000 ставится на паузу до следующего месяца.
- Комментарии и отзывы: бесплатно и в этот лимит не входят.
- Директ в X и SMS считаются отдельно. Для WhatsApp, кроме Zernio, счёт выставляет Meta за шаблоны.

**Противоречие про «Inbox от 10 долларов».** Ты мог видеть, что директ и комментарии продаются как отдельное дополнение от 10 долларов. Что известно на 10.10.2026:

- Страницы docs.zernio.com/pricing и zernio.com/pricing говорят: отдельной платы за входящие нет, они входят в каждый аккаунт.
- Блог Zernio от 6 мая 2026 («We killed our pricing tiers») говорит: старые тарифы и дополнения (Аналитика, «Комментарии и директ», Рекламный API) отменены. Раньше они стоили «от 10 до 1000 долларов в месяц» в зависимости от тарифа. Видимо, «10 долларов» это нижняя граница старой цены.
- Ошибка `403 INBOX_REQUIRED` бывает только на старых («legacy») планах. Такой аккаунт можно перевести на новую схему из панели.
- Сторонние каталоги (Capterra, GetApp) показывают 15 или 19 долларов. Они устарели.

Вывод: на сегодня дополнения нет, директ входит в цену аккаунта. Противоречие осталось только на старых страницах и в сторонних каталогах. Если в твоём аккаунте всё-таки просят оплатить дополнение, напиши в поддержку Zernio.

## Куда положить ключ

Правило одно для всех сервисов. Ключ никогда не вставляй в чат с агентом.

1. Скопируй ключ из панели сервиса.
2. Открой Блокнот, вставь ключ и сохрани файл `Загрузки\<сервис>-key.txt`. Здесь `<сервис>` это короткое имя сервиса, например `zernio`.
   Имена файлов одни на весь курс: `zernio-key.txt`, `openai-key.txt`, `openrouter-key.txt`, `telegram-bot-key.txt`, `server-key.txt`, `google-sheets-key.txt`, `elevenlabs-key.txt`, `higgsfield-key.txt` (если ключ нужен).
3. Напиши агенту только это: «Ключ лежит в файле Загрузки\<сервис>-key.txt». Само значение не пиши.
4. Агент сам прочитает файл и положит значение в переменную окружения или в файл `.env` на сервере. На экране он значение не показывает.
5. После этого агент удаляет файл `Загрузки\<сервис>-key.txt`. Проверь сам, что файла в Загрузках больше нет.
6. Если ключ всё-таки попал в чат, скриншот или публичный репозиторий, сразу удали его в панели сервиса и создай новый.

Для этой инструкции файл называется `Загрузки\zernio-key.txt`. Секрет подписи вебхука ты не вводишь, его создаёт и хранит агент.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| `401 Unauthorized` при запросе к API | Ключ неверный или с лишним пробелом, либо удалён. Создай новый на https://zernio.com/dashboard/api-keys |
| `403 insufficient_permissions`, в тексте сказано про группу `messages` | У ключа отключена группа ресурсов. Создай новый ключ с включённой группой `messages` (и `webhooks`). Можно ли менять группы у готового ключа, в документации не сказано, поэтому проще создать новый |
| `403 INBOX_REQUIRED` | Это старый («legacy») план. Переключись на новую схему оплаты в панели или напиши в поддержку |
| `402` при подключении аккаунта, причина `free_tier_exceeded` | Это не про WhatsApp, а про любой аккаунт сверх бесплатных двух: в профиле нет карты. Добавь карту на https://zernio.com/dashboard?tab=billing |
| `429` (слишком много запросов) | Подожди столько секунд, сколько указано в `Retry-After`. Лимит: 60 запросов в минуту, пока подключено до 2 аккаунтов, 600 в минуту от 3 аккаунтов |
| «Instagram access token expired» | Переподключи Instagram-аккаунт |
| В Zernio нет старой переписки Instagram | В настройках Instagram включи доступ к сообщениям («Connected tools») и подключи аккаунт заново |
| Telegram: «Bot is not a member of the channel» | `@ZernioScheduleBot` должен быть администратором с правом «Post Messages». Простого участника недостаточно |
| Telegram: код не принимается | Код живёт 15 минут. Запроси новый |
| WhatsApp: `one_whatsapp_per_profile`, `whatsapp_number_already_connected` | Номер уже подключён в другом профиле. Один номер может быть активен только в одном профиле |
| Вебхук не приходит | Проверь: адрес с `https://`, виден из интернета, сервер отвечает `2xx` быстрее 5 секунд. Загляни в журнал доставок на https://zernio.com/dashboard/webhooks. Через 3 дня сбоев адрес могут отключить |
| `409` при публикации поста | Тот же текст и то же видео на тот же аккаунт уже выходили в последние 24 часа. Измени подпись или файл, либо найди исходный пост (в ответе есть его id) |
| Подпись вебхука не совпадает | Считай HMAC-SHA256 от сырого тела запроса, а не от разобранного JSON, и тем же секретом, который передан в Zernio |
| В Claude Code `zernio` в `/mcp` не «connected», ошибка 401 | Удали сервер и добавь заново, затем войди через браузер. После этого полностью перезапусти Claude |
