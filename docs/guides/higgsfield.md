# Higgsfield из Claude: картинки, видео и голос для роликов (и что с Kling и Seedance)

Сверено с официальными страницами на 10.10.2026. Где ответа нет или страницы противоречат друг другу, стоит пометка «проверь на месте».

## Что это и зачем

Higgsfield (higgsfield.ai) это сервис, где в одном месте собраны больше 30 моделей, которые рисуют картинки и снимают видео по описанию. Внутри есть Kling, Seedance, Veo, Wan, Nano Banana и другие. Когда он подключён к Claude, агент сам придумывает описание, запускает генерацию и кладёт готовый файл в монтаж.

Зачем это ролику:

- **Предмет по смыслу фразы.** Нужен 3D-предмет или иллюстрация, которых нет в `public/objects`.
- **Фон.** Например, строящееся здание за спиной у говорящего (`higgsfield-talking-offer.md`).
- **Видеовставка или переход**, когда готового демо нет.
- **Голос.** Озвучка текста для ролика без лица.

Чего Higgsfield не делает для нас: логотипы сервисов (только настоящие из `public/brand`) и интерфейсы продуктов (их снимает `capture-ui`).

## Что понадобится

- Claude Desktop и подписка Claude Pro или Max (`claude-desktop.md`). Claude не бесплатный.
- **Платная подписка Higgsfield.** Без неё подключение не работает: в справке Higgsfield написано «An active paid subscription is required».
- Каждая генерация через Claude списывает кредиты. Бесплатные генерации и «безлимит» работают только на сайте higgsfield.ai, через Claude их нет.
- Оплата картой через Stripe (так сказано в условиях Higgsfield). Подойдёт ли карта банка твоей страны, в условиях не сказано.
- Ключ API не нужен: вход идёт через браузер.

## Шаги

### 1. Оформи подписку Higgsfield

1. Открой https://higgsfield.ai и зарегистрируйся (пароль и оплату вводишь ты сам).
2. Перейди на страницу тарифов и выбери тариф. Для начала хватит самого дешёвого с кредитами. Цены ниже.

### 2. Подключи Higgsfield к Claude

Два пути. Первый нужен для обычного чата, второй для вкладки **Code**, где работает Монтажёр.

**Путь А. Чат в Claude Desktop (коннектор).** Картинка с этим разделом: `img/guide-06.png`.

1. Открой Settings → Connectors (в некоторых версиях раздел называется Customize → Connectors).
2. Нажми «Add custom connector».
3. Имя: `Higgsfield`. Адрес сервера: `https://mcp.higgsfield.ai/mcp`.
4. Нажми «Connect». Откроется окно Higgsfield. Войди в аккаунт и разреши доступ. Если ты уже вошёл на higgsfield.ai, этот шаг пройдёт сам.
5. Higgsfield появится в списке подключённых коннекторов.

Если у тебя рабочий план Claude (Team или Enterprise), администратору может понадобиться добавить этот адрес в разрешённые.

**Путь Б. Вкладка Code (через CLI, его ставит агент).** Higgsfield рекомендует для Claude Code именно его. Скажи Монтажёру: «Подключи Higgsfield». Агент выполнит три команды, а ты только войдёшь в браузере:

1. `npm i -g @higgsfield/cli` ставит программу.
2. `higgsfield auth login` открывает браузер. Входишь ты сам. Ключ не нужен.
3. `npx skills add higgsfield-ai/skills` ставит навыки для агента. Их несколько: `higgsfield-generate` (картинки и видео), `higgsfield-soul-id` (постоянный персонаж), `higgsfield-product-photoshoot`, `higgsfield-brandkit`, `higgsfield-marketplace-cards`, `higgsfield-video-explainer`, `higgsfield-websites`, `higgsfield-youtube-thumbnail`.

Проверь на месте, виден ли коннектор из пути А внутри вкладки Code. Для монтажа надёжнее путь Б.

### 3. Проверь, что всё работает

Напиши агенту: «Какой у меня баланс кредитов в Higgsfield?» (так советует сама справка). Если баланс назвали, подключение живое.

### 4. Первая генерация

1. Попроси самую дешёвую вещь: картинку. «Сгенерируй картинку красной кирпичной стены, вертикальный формат 9:16. Сначала скажи цену и жди моего «да».»
2. Назови агенту «да» только после цены. Жёсткого ограничения расходов у Higgsfield нет, «спрашивай перед тратой» это просьба в разговоре, а не замок.
3. Готовый файл появится в Assets на higgsfield.ai обычно в течение минуты после завершения. Агент скачает его в проект.

### 5. Как это встроено в монтаж

Правило для Монтажёра (шаг 4Г в `.claude/skills/onai-montage/reference/04-build.md`): генерировать только по слову владельца, сначала назвать цену, файл сохранить в `public/work/<ролик>/gen/`, промпт и модель записать в `work/<ролик>/ASSET_SOURCES.md`. Повторно один и тот же файл не генерировать.

## Какую модель брать

Названия моделей в командах агента (проверено по репозиторию https://github.com/higgsfield-ai/cli, список полностью: `higgsfield model list`).

| Что нужно | Модель | Заметка |
|---|---|---|
| Картинка высокого качества | `nano_banana_2` | **это Nano Banana Pro**, не Nano Banana 2 |
| Картинка быстрее и дешевле | `nano_banana_flash` | **это Nano Banana 2**. Названия в списке перепутаны, не ориентируйся на цифру |
| Картинка другого вида | `seedream_v4_5`, `gpt_image_2`, `kling_omni_image` | проси агента показать цену до запуска |
| Видео, основной выбор | `kling3_0` | 3–15 с, 720p, 1080p и 4K, звук в том же проходе |
| Видео, черновик | `kling3_0_turbo` | быстрее, до 1080p |
| Видео с речью и референсами | `seedance_2_5`, `seedance_2_0` | подробнее ниже, раздел про Seedance |
| Видео дешевле | `seedance_2_0_mini`, `kling2_6` | 720p |
| Видео киношное | `veo3_1`, `wan2_7` | по желанию |
| Озвучка | `text2speech_v2` (в параметрах `--variant elevenlabs`), `seed_audio` | `higgsfield voices list` показывает голоса |
| Убрать фон | `image_background_remover`, `video_background_remover` | формат результата у видео проверь на пробном файле |

## Kling

Kling это видеомодель компании Kuaishou. Подключить её можно двумя способами.

**Внутри Higgsfield.** Это те же Kling 3.0, 3.0 Turbo, 3.0 Omni, Motion Control, Kling 2.6 и Kling Avatars 2.0 (говорящий аватар из фото и аудио, в Lipsync Studio). Отдельный аккаунт Kling не нужен, платишь кредитами Higgsfield. Список версий и длительностей: https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-kling.

**Отдельно у Kling.** У Kling есть свой официальный коннектор для Claude и своя программа для агента.

- Коннектор: Settings → Connectors (или Customize → Connectors) → «Add custom connector», имя `klingai`, адрес `https://kling.ai/mcp`, затем «Connect» и вход в аккаунт Kling. В Claude Code та же настройка: `claude mcp add --transport http klingai --scope user https://kling.ai/mcp`, потом `/mcp` и вход. Это пересказ руководства Kling https://kling.ai/app/mcp/guide, сверь шаги на экране.
- Программа для агента: пакет `@klingai/cli-global` (команду входа проверь у агента: `kling --help`). Навыки Kling для агента не ставим: репозитории навыков не входят в официальную документацию.
- Что оплачивается: тариф Kling. Через Claude работают только платные кредиты личного кабинета. Бонусные кредиты и бесплатная генерация «в непиковые часы» через ассистентов недоступны. Неудачная генерация возвращает кредиты (по правилам Kling).
- Что умеет Kling 3.0 (страница возможностей https://kling.ai/document-api/guides/capability-map/video.md): 3–15 секунд, 720p, 1080p и 4K, картинка в видео, кадр начала и конца, Motion Control, звук в том же проходе. Формат 9:16 на этой странице не назван, проверь на пробном клипе.
- Условия Kling: результат помечается «Kling AI» (пункт 4.5), если пометить нельзя, пиши название в заголовке.

## Seedance

Seedance это видеомодель ByteDance. Она сама генерирует звук и речь с движением губ, умеет брать картинки, видео и аудио как референсы.

**Внутри Higgsfield** (справка https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance):

| Версия | Длительность | Разрешение | Референсы за раз |
|---|---|---|---|
| Seedance 2.5 | 4–30 с | до 1080p | до 30 картинок, 10 видео, 10 аудио |
| Seedance 2.0 | 4–15 с | от 480p до 4K | до 9 картинок, 3 видео, 3 аудио |
| Seedance 2.0 Fast и Mini | 4–15 с | 480p–720p | как у 2.0 |

- Seedance 2.5 не входит в самые дешёвые тарифы (в справке: «Not included in Starter or Basic»).
- Звук идёт в том же проходе, что и картинка. Движение губ работает на нескольких языках, список языков в справке не назван.
- Загруженная голосовая дорожка подключается тегом `@audio` в описании: модель подстроит видео под неё и сделает движение губ.
- Совет Higgsfield: начинай с картинки в видео в 720p, смотри весь клип (ошибки часто на 5–8 секунде), меняй за раз одно.
- Через Claude это тот же коннектор или CLI: модели `seedance_2_5`, `seedance_2_0`, `seedance_2_0_mini`.

**Отдельно у ByteDance.**

- Dreamina (dreamina.capcut.com) это сайт для людей. Платные тарифы называются Basic, Standard, Advanced и Super. На странице Dreamina от 08.10.2026 для первого месяца Basic указаны ориентиры на 720p: Seedance 2.5 около 0,035 доллара за секунду, Seedance 2.0 Pro около 0,016, Fast и Mini около 0,008 (это цены акции первого месяца). В документации Dreamina готового коннектора для Claude нет.
- BytePlus ModelArk это официальный API для разработчиков, оплата по токенам (по пересказам, страницу тарифов проверь на месте). Официального коннектора для Claude у ModelArk в документации нет, есть только сторонние серверы MCP. Новичку этот путь не нужен: проще через Higgsfield.

## Сколько это стоит

Цены Higgsfield по блогу Higgsfield, сверены 11.09.2026 (https://higgsfield.ai/blog/credits-vs-unlimited-ai-video-generation). Страницы Higgsfield между собой расходятся (встречаются другие суммы и тариф Basic), поэтому перед покупкой открой https://higgsfield.ai/pricing.

| Тариф | В месяц | Кредитов в месяц |
|---|---|---|
| Starter | 15 $ | 200 |
| Plus | 49 $ (39 $ при оплате за год) | 1000 |
| Ultra | 129 $ (99 $ за год) | 3000 |

Примеры расхода (там же и в блогах Higgsfield, точная цифра всегда на кнопке «Generate»):

| Что | Кредитов |
|---|---|
| Kling 3.0, 8 секунд, 1080p | около 20 (примерно 1 $) |
| Seedance 2.5, 8 секунд, 1080p | около 72 |
| Seedance 2.5, 14 секунд, 720p, с речью | около 91 |
| Seedance 2.0, 8 секунд, 720p | около 36 (блог от июня 2026) |
| Картинка Soul 2.0 | 0,125 |

Для сравнения, отдельный Kling: тариф Standard 6,99 $ только в первый месяц, дальше 8,80 $, 660 кредитов; Pro 25,99 $ в первый месяц, дальше 32,56 $, 3000 кредитов (блог Kling от 28.07.2026).

Подписки продлеваются автоматически. Отменить можно на странице «Payment Setting» в аккаунте или письмом в поддержку, доступ остаётся до конца оплаченного срока, деньги за текущий срок не возвращаются. Возврат в течение 7 дней после первой покупки возможен, если кредиты не тратились (условия Higgsfield, пункты 9.3 и 10).

## Что нельзя

- Чужое лицо и голос только с согласием человека (условия Higgsfield, пункт 5.3). Higgsfield пишет, что сервис для выдуманных и согласованных аватаров, а не для воссоздания реальных людей без разрешения.
- Там, где закон требует, пиши, что видео сгенерировано ИИ (условия Higgsfield, пункт 5.5). Метки на результате не удаляй.
- Не генерируй логотипы сервисов и интерфейсы продуктов: только настоящие.

## Куда положить ключ

Ключ не нужен: Higgsfield и Kling входят через браузер. Если когда-нибудь у Higgsfield появится ключ API, сохрани его по общему правилу: файл `Загрузки\higgsfield-key.txt`, агенту напиши только «Ключ лежит в файле Загрузки\higgsfield-key.txt», агент положит значение в `.env` и удалит файл. Ключ в чат не вставляй никогда.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| «Not authenticated» или «Session expired» | Короткие сессии Higgsfield кончились. Агент запускает `higgsfield auth login` снова, ты входишь в браузере |
| Коннектор добавлен, но во вкладке Code Higgsfield не виден | Берём путь Б (CLI): скажи Монтажёру «Подключи Higgsfield» |
| Подключиться к коннектору не даёт рабочий план Claude | Администратору нужно разрешить адрес `https://mcp.higgsfield.ai/mcp` |
| Кредиты ушли быстрее, чем ждал | Агент сначала называет цену. Договорись: «без моего «да» не запускай». Жёсткого лимита нет |
| В Seedance 2.5 нет в списке | Он не входит в Starter. Бери Seedance 2.0 или подними тариф |
| Не тот Nano Banana | `nano_banana_2` это Pro, `nano_banana_flash` это Nano Banana 2. Смотри на название на экране, а не на цифру |
| Результата нет в Assets | Подожди минуту, попроси агента показать список генераций |
| Kling просит отметку «Kling AI» | Добавь её в заголовок публикации, если пометить сам ролик нельзя |
| «Бесплатные генерации» не списываются через Claude | Так и задумано: безлимит только на сайте higgsfield.ai |
