# Лучшее время выкладки: как найти своё, а не поверить в «волшебный час»

Проверено по документации Zernio и Instagram 10.10.2026. Полный метод для агента: `.claude/skills/onai-montage/reference/05-series-publish.md`, раздел «Лучшее время выкладки».

## Что это и зачем

Универсального «лучшего часа» нет. У каждого блога своя аудитория: кто-то смотрит утром по дороге, кто-то поздно вечером. Чужие советы про час не заменят твоих цифр. Нужно две-три недели выкладывать ролики в разное время и сравнить результаты.

## Что понадобится

- Работающий ассистент и подключённый Zernio: выкладка и статистика идут через него (`zernio.md`). Пока ассистента нет, ролики выкладываешь сам, а цифры из статистики приложения записываешь в таблицу вручную.
- Ролики одного формата и сопоставимого качества. Две версии одного голоса подряд не выкладывай.
- Python на компьютере (его ставит агент). Ключей для скрипта не нужно.

## Шаги

### 1. Выбери пояс аудитории и слоты

Аудитория чаще всего в Казахстане (UTC+5, Алматы и Астана) и России (Москва UTC+3, дальше пояса разные). Выбери главный пояс и считай слоты по его времени. Для сравнения: время в Алматы минус 2 часа равно времени в Москве.

Возьми одну из двух схем:

- **3 слота на 2 недели.** 14 роликов, каждый слот получит 4–5 роликов, и в будни, и в выходные. Например: обед (12:00), вечер (20:00), поздний вечер (23:00).
- **5 слотов на 3 недели.** 21 ролик, тоже по 4–5 на слот. Например: утро (8:00), обед (12:00), ранний вечер (16:00), вечер (20:00), поздний вечер (23:00).

5 слотов на 2 недели не бери: на слот выйдет 2–3 ролика, а для сравнения нужно не меньше 3 (скрипт ответит «Мало данных»). Агент выставляет время сам (`scheduledFor` и `timezone`).

### 2. Две или три недели по одному ролику в день

- Меняй слот по кругу так, чтобы каждый слот попал и на будни, и на выходные. Перед стартом выпиши даты каждого слота и проверь, что среди них есть и будни, и выходной.
- Пробные рилсы Instagram сначала видят люди, которые на тебя ещё не подписаны. Сравнивай пробные рилсы только с пробными.
- Пробный рилс к подписчикам переводишь ты сам в приложении Instagram, по умолчанию агент ставит режим `MANUAL`. Режим `SS_PERFORMANCE` включается только по твоему слову: Instagram сам делится рилсом с подписчиками, если он хорошо идёт; решает по просмотрам за первые 72 часа, порог не опубликован.

### 3. Сними цифры через 48 часов

По каждому ролику записывай: просмотры, **долю пропуска в первые 3 секунды**, среднее время просмотра. Для Instagram Reels Zernio отдаёт эти поля сам (`reelsSkipRate` в процентах и `igReelsAvgWatchTime` в миллисекундах; Meta называет долю пропуска оценочной). Для TikTok и YouTube доля пропуска в документации Zernio не заявлена, смотри просмотры и среднее время просмотра.

Агент снимает их командой Zernio (`GET /v1/analytics`) и дописывает в таблицу `work/_profile/post-stats.csv`:

```
published_at,platform,post_id,views,reach,skip_rate,avg_watch_ms,saves,shares
2026-10-12T15:00:00Z,instagram,abc123,8400,9100,36,9200,70,41
```

Сравнивать можно только ролики одного возраста: снимай каждый через 48 часов после выкладки. Названия полей в ответе Zernio проверь на месте при первом снятии: скрипт ищет несколько вариантов названий, а в документации показан пример только для одного поста.

### 4. Сравни слоты

Агент запускает:

```
python scripts/best-time.py work/_profile/post-stats.csv --tz Asia/Almaty --slots 12,20,23
```

Часы в `--slots` должны совпадать с теми, в которые ты выкладывал (для схемы на 5 слотов: `--slots 8,12,16,20,23`).

Скрипт напечатает по каждому слоту: сколько роликов, медиану просмотров, медиану пропуска, среднее время просмотра. Правило курса (рабочее, не закон статистики): в слоте должно быть не меньше трёх роликов; разница в просмотрах меньше 20% считается ничьей; при ничьей смотрят долю пропуска, меньше лучше.

Проверить сам скрипт можно командой `python scripts/best-time.py --selftest`.

### 5. Выбери слоты и повтори через месяц

Оставь 1–2 лучших слота. Раз в месяц повтори эксперимент на одной-двух неделях: победитель и один новый слот. Аудитория меняется.

## Чего здесь нет

- Чудо-часа. Две-три недели и 14–21 ролик это маленькая выборка. Тема и первые 3 секунды влияют на результат сильнее часа.
- Помощник Zernio `GET /v1/analytics/best-time` считает по лайкам, комментариям, репостам и сохранениям, в UTC, и ему нужен доступ к аналитике. Он не смотрит на просмотры и на пропуск. Как подсказку использовать можно, как решение нет.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| Скрипт пишет «Мало данных» | В слоте меньше трёх роликов. Выкладывай дальше |
| Все слоты выглядят одинаково | Ничья это тоже ответ: время не главное, работай над первыми 3 секундами |
| Ответ Zernio 402 при запросе статистики | Нет доступа к аналитике. Смотри раздел про цену в `zernio.md` |
| Пояс `Asia/Almaty` не найден | На Windows поставь пакет tzdata (`pip install tzdata`) или добавь `--utc-offset 5` |
| В файле нет ни одного поста с датой и просмотрами | Проверь названия столбцов: `published_at` и `views` обязательны |
