# Apify: собрать залетевшие рилсы конкурентов

Сверено 11.10.2026: страница тарифов Apify, документация API, публичная карточка актёра. Названия кнопок взяты с экрана владельца курса. Где ответа нет, стоит пометка «проверь на месте».

## Что это и зачем

Apify (apify.com) это магазин готовых программ-«актёров», которые собирают данные из интернета. Нам нужен один: **Instagram Reel Scraper**. Ты даёшь ему аккаунты, он возвращает рилсы с просмотрами, лайками, датой, подписью и адресом видео.

Дальше работает чат «Скрипты для Reels»: скачивает самые сильные ролики в папку референсов, разбирает их хуки и пишет три первых текста для тебя. Чужой ролик это идея и приём, а не текст: свой текст пишется про твоё дело.

Порог просмотров, который советует автор курса: **от 25 тысяч**. В своей нише он ищет от 50 тысяч: такие ролики с большей вероятностью залетают снова.

## Что понадобится

- Почта Google (Gmail) или любая другая для регистрации.
- Три открытых Instagram-аккаунта конкурентов или экспертов твоей ниши. Закрытые аккаунты не читаются.
- Чат «Скрипты для Reels» в папке проекта.
- Банковская карта не нужна: на бесплатном тарифе Apify FAQ пишет «No credit card is required».

## Шаги

### 1. Зарегистрируйся в Apify

1. Открой https://apify.com и нажми **Get started** (кнопка справа вверху).
2. Войди, например, через Gmail. Пароль, код из письма и капчу вводишь ты сам.

### 2. Проверь бесплатный лимит

В левом меню внизу видно **RAM 0 MB / 16 GB** и **Usage $0.00 / $5.00**. Это бесплатный тариф: 5 долларов платформенных кредитов в месяц (страница тарифов Apify). Когда кредиты кончаются, доступ закрывается до следующего месячного цикла, платить ничего не нужно.

### 3. Скопируй ключ

1. В левом меню нажми **Settings**.
2. Открой вкладку **API & Integrations**.
3. В блоке **Personal API tokens** найди строку **Default API token created on sign-up**. Справа от звёздочек два значка: «глаз» показывает ключ, соседний копирует его.
4. Нажми значок копирования.

### 4. Отдай ключ агенту

Вставь ключ в чат «Скрипты для Reels» так: «Мой ключ Apify: <ключ>. Запиши его в .env и нигде не повторяй». Агент запишет его в файл `.env` в папке проекта строкой `APIFY_TOKEN=...`, проверит, что `.env` не попадает в git (он есть в `.gitignore`), и ответит только «записал». Файл в «Загрузках» делать не нужно.

Ключ даёт доступ к твоему аккаунту Apify и тратит его кредиты, поэтому его не нужно показывать на скриншотах и в публичных репозиториях. Если он попал куда не надо: в том же блоке нажми **Create a new token** и пользуйся новым, а старый удали или обнови кнопками рядом с ним (у стандартного токена кнопка **Delete** на экране владельца была серой, проверь на месте).

### 5. Запусти сбор

Напиши в чат «Скрипты для Reels»:

«Твоя задача: проанализировать три Instagram-аккаунта моих конкурентов и скачать опубликованные за последние два месяца ролики, набравшие больше 25 000 просмотров. Аккаунты: @ник1, @ник2, @ник3».

Агент покажет оценку расхода и запустит скрипт `npm run apify -- --accounts @ник1,@ник2,@ник3 --min-views 25000 --months 2`. Можно давать ссылки на профили вместо ников. Порог и срок меняются словами: «от 50 тысяч», «за три месяца».

### 6. Получи результат

В папке `work/_refs/<дата>/` лежат:

- видео `<аккаунт>-<код ролика>.mp4` (лучшие по просмотрам, по умолчанию до 20 штук);
- `index.md`: таблица со ссылкой, датой, просмотрами, лайками, комментариями, длительностью и подписью каждого ролика, внизу расход запуска;
- `index.json`: те же данные для агента.

Папка `work/_refs/` не уходит в git. Следующий шаг: «Разбери все мои референсы на основе наших навыков копирайтинга и составь первые три текста для Reels» (`docs/guides/lesson-1-2-flow.md`).

## Сколько это стоит

| Что | Цена | Откуда |
|---|---|---|
| Бесплатный тариф Apify | 5 $ платформенных кредитов в месяц, карта не нужна | страница тарифов, 11.10.2026 |
| Один рилс в результате (тариф Free) | 0,0026 $, то есть 2,60 $ за 1 000 | публичная карточка актёра через API Apify, 11.10.2026 |
| Запуск актёра | 0,001 $ | там же |
| Пример: 3 аккаунта по 40 рилсов | около 0,31 $ | расчёт по ценам выше |
| Хватит на | около 1 900 рилсов в месяц | 5 $ делить на 0,0026 |

Шапка страницы актёра пишет «from $1.00 / 1,000 reels»: это цена самого дорогого тарифа. На бесплатном тарифе считай по 2,60 $ за 1 000.

Платные добавки актёра мы не включаем: скачивание видео силами Apify стоит 0,02 $ за мегабайт (ролик в 10 МБ обошёлся бы в 0,20 $), расшифровка 0,048 $ за минуту, число репостов только на платном тарифе. Видео скачивает наш скрипт напрямую, расшифровку делает `npm run transcribe`. Скрипт сам не даёт одному запуску потратить больше 1 $ (параметр `--max-usd`).

## Что нельзя

- Только открытые аккаунты и открытые данные. Актёру не нужен твой логин Instagram: в его настройках нет полей для логина и пароля.
- Чужие ролики только как референс: берём идею и приём хука, не текст, не кадры, не голос.
- Данные людей из комментариев не собираем. Скрипт не сохраняет комментарии, хотя актёр отдаёт до 10 последних.
- Ссылки на видео живут недолго, поэтому ролики скачиваются сразу во время сбора. Если файл не скачался, запусти сбор заново.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| «Apify не принял ключ» (код 401) | Проверь строку `APIFY_TOKEN=` в `.env` или выпусти новый ключ (шаг 4) |
| «Бесплатные кредиты Apify закончились» (код 402) | Дождись нового месяца или переведи тариф на платный (страница Billing) |
| «Empty or private data for provided input» | Аккаунт закрыт или ник написан с ошибкой |
| Ни один рилс не прошёл порог | Понизь порог до 10 000 или возьми более крупные аккаунты |
| «Не скачался» | Ссылка на видео устарела: запусти сбор ещё раз |
| Просмотров нет, а лайки -1 | Автор скрыл лайки, в таблице будет «скрыто» |

## По желанию: Apify как MCP

У Apify есть сервер MCP `https://mcp.apify.com`: Claude запускает актёров сам, вход через OAuth в браузере, ключ в чат не нужен (документация Apify, 11.10.2026). Пошаговой настройки для Claude Desktop на странице нет, проверь на месте. Основной путь курса это скрипт: он сам считает порог, скачивает видео и пишет список.
