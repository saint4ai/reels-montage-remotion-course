# Ключи стоков: Pixabay, Unsplash, Pexels

Сверено 11.10.2026 по документации сервисов. Где страница не назвала шаг, стоит пометка «проверь на месте».

## Нужны ли они вообще

Нет. Чат «Скрипты для Reels» умеет искать материалы на сайтах Mixkit, Coverr, Pixabay и Pexels в браузере, без ключа, и скачивать их руками. Ключ ускоряет поиск: агент спрашивает сервис напрямую и скачивает много файлов за раз. Поэтому ключ можно получить позже, когда материалов потребуется много.

Сначала свои кадры: фото и видео твоей работы лучше любого стока. Где что искать: `.claude/skills/onai-scriptolog/references/materials-sources.md`.

## Что понадобится

- Почта для регистрации на каждом сервисе (каждый просит свой аккаунт).
- Бесплатно: все три ключа даются без оплаты.
- Чат «Скрипты для Reels».

## Pixabay (видео, фото)

1. Открой https://pixabay.com и войди или зарегистрируйся. Пароль и код из письма вводишь ты сам.
2. Открой https://pixabay.com/api/docs/. По документации Pixabay, ключ виден на этой странице после входа. Где именно он написан, проверь на месте.
3. Скопируй ключ и отдай агенту (раздел ниже).

Лимиты (документация Pixabay): 100 запросов за 60 секунд. Ответы агент хранит у себя 24 часа, массово скачивать запрещено.

## Unsplash (только фото)

1. Открой https://unsplash.com/oauth/applications и войди. Это страница для разработчиков (документация: «Join as a developer»).
2. Нажми **New Application**, прими условия и опиши приложение одной фразой, например «сбор фото для моих роликов». Названия полей на экране проверь на месте.
3. На странице созданного приложения скопируй **Access Key**.

Лимиты (документация Unsplash): новое приложение работает в «demo mode», 50 запросов в час. Для большего лимита нужна заявка «Apply for Production». Видео в Unsplash нет.

## Pexels (видео, фото)

1. Открой https://www.pexels.com/api/.
2. **На 11.10.2026 на этой странице написано: «New API key issuance is currently paused».** Выдача новых ключей приостановлена, поэтому новичку ключ там не получить. Когда выдачу вернут, шаги такие: войти или зарегистрироваться на pexels.com, нажать **Get Started** и получить ключ, который по описанию страницы приходит сразу.
3. Пока ключа нет, ищи видео на самом сайте pexels.com: он работает без ключа.

Лимиты (документация Pexels): 200 запросов в час и 20 000 в месяц.

## Coverr (видео)

Бесплатный API у Coverr есть (api.coverr.co/docs), как получить ключ, страница документации не сообщила, проверь на месте. Для новичка проще искать на сайте coverr.co.

## Как отдать ключ агенту

Решение владельца курса (11.10.2026): файл в «Загрузках» делать не нужно. Вставь ключ в чат «Скрипты для Reels» сообщением вида:

«Ключ Pixabay: <ключ>. Запиши его в .env и нигде не повторяй».

Агент запишет его в файл `.env` в папке проекта строкой `PIXABAY_API_KEY=...` (для Unsplash `UNSPLASH_ACCESS_KEY`, для Pexels `PEXELS_API_KEY`, для Coverr `COVERR_API_KEY`), проверит, что `.env` не попадает в git, и ответит одним словом «записал». Ключ не появится в ответах, журналах и файлах для публикации.

Ключи стоков бесплатные и открывают только поиск, но не показывай их на скриншотах и в публичных репозиториях. Если ключ попал куда не надо, выпусти новый в личном кабинете сервиса.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| Код 429 «Too Many Requests» | Лимит исчерпан (раздел с лимитами у сервиса). Подожди час или ищи на сайте руками |
| Код 401 или 403 | Ключ вставлен с пробелом или не тот. Пришли его ещё раз, агент перезапишет строку в `.env` |
| В Pixabay много горизонтальных видео | В его API у видео нет фильтра ориентации: агент отбирает вертикальные по ширине и высоте файла |
| Сайт открывает страницу проверки браузера | Ищи в окне браузера Claude, а не скриптом |
