# Доска раскадровки: правки по кадрам мышкой

Сервер, сборку доски и сдвиги проверяет тест `npm run board:test`. Надписи на кнопках страницы могут отличаться от описания: ориентируйся на смысл, а если не совпало, скажи агенту, что видишь.

## Что это и зачем

Доска это страница на твоём компьютере. На ней все кадры ролика с номерами К001, К002 и так далее. Ты открываешь кадр и говоришь, что не так, прямо на нём:

- ставишь оценку («Нравится», «Нужна правка», «Вопрос»);
- пишешь комментарий, он привязан к секунде видео и к кадру;
- прикладываешь референс: скриншот или видео нужной анимации, либо ссылку;
- **двигаешь объекты стрелкой**: тянешь мышкой от объекта к новому месту, подписываешь, что двигаем, и при желании выбираешь «крупнее» или «мельче».

Агент читает всё это сам, в пикселях кадра, исправляет сцену в коде и отвечает в ветке под твоим комментарием. Не нужно писать в чате «где-то на седьмой секунде, чуть левее».

Все правки по кадрам идут через эту доску. Storybook в курсе нет, и вместо него именно доска: кадр за кадром, с оценками и стрелками.

## Что понадобится

- Папка проекта с курсом, в которой уже собран ролик (`npm run frames` построил лист кадров).
- Браузер на компьютере (любой). Входить никуда не нужно, доска работает только у тебя.
- Node.js и ffmpeg. Их ставит агент (`npm run doctor`).
- Ключи и аккаунты не нужны. Страница доски ничего не загружает из интернета и ничего туда не отправляет.

## Шаги

### 1. Собери доску

Скажи агенту: «Собери доску раскадровки для ролика». Он выполнит две команды:

1. `npm run frames -- <композиция>` построит кадры К001… каждые 2 секунды и лист `reviews/<композиция>-vNNN/`.
2. `npm run board -- <композиция>` соберёт из них доску в `work/<ролик>/storyboard/`.

Если уже есть черновик `out/<композиция>-draft.mp4` (его делает `npm run draft`), доска возьмёт его копию 720p, и в каждом кадре можно будет проиграть свой кусок видео. Без черновика на доске видны только кадры, стрелки и комментарии работают так же.

Речь в подписях кадров появится, если рядом лежит расшифровка `work/<ролик>/words.json` (`npm run transcribe`).

Новая версия ролика: пересобери кадры и скажи «пересобери доску». Оценки, комментарии, вложения и стрелки сохраняются на своих номерах кадров.

### 2. Открой доску

Скажи агенту «запусти доску» (он выполнит `npm run board:open`) и открой в браузере адрес http://localhost:4321. В Windows можно открыть папку `tools\storyboard` и дважды щёлкнуть `start.cmd`. Остановить доску: закрыть окно с чёрным фоном или попросить агента.

Сверху лента кадров по времени, слева сетка кадров, справа панель выбранного кадра. Стрелки ← и → на клавиатуре листают кадры. Кнопка «Как работать» вверху напоминает шаги.

### 3. Оцени кадр и напиши комментарий

1. Нажми на кадр.
2. Выбери оценку или оставь поле «Заметка».
3. В блоке «Комментарии» напиши, что исправить: «Телефон почти прозрачный, вход сделай быстрее». Галочка «привязать к моменту видео» запоминает секунду. Отправить можно кнопкой или Ctrl+Enter.
4. В поле «Я» наверху можно поменять подпись автора.

### 4. Приложи референс

В блоке «Вложения» перетащи скриншот или видео нужной анимации, либо вставь из буфера обмена (Ctrl+V). Ссылку на ролик-образец добавь в блок «Ссылки». Агент увидит файлы и посмотрит их перед правкой.

### 5. Передвинь объект стрелкой

1. Под кадром нажми **«↔ Сдвиг объектов»**. Вместо видео появится картинка кадра, курсор станет крестиком.
2. Нажми на объект и, не отпуская кнопку мыши, протяни стрелку к новому месту. Отпусти.
3. Внизу появится форма. Напиши, что двигаем («телефон», «заголовок»), при желании выбери «крупнее ×1,25», «ещё крупнее ×1,5», «мельче ×0,8» или «ещё мельче ×0,6» и нажми «Сохранить стрелку» (или Enter).
4. Стрелок можно поставить несколько. У каждой свой номер и подпись, они видны на кадре поверх картинки и в списке «Сдвиги объектов».
5. Ошибся: нажми «Удалить» в списке. Короткая стрелка (меньше 40 пикселей кадра) не сохраняется, это считается случайным нажатием. Escape отменяет стрелку, которую ещё не сохранил.

Агент получает положение в долях кадра и в пикселях кадра 1440×2560 (не 4K: размеры композиции одни, масштаб 1,5 включается только при рендере). Например, стрелка от верхнего левого угла телефона к центру:
`из (360, 1024) px в (720, 1280) px, сдвиг +360 по x и +256 по y`.

### 6. Скажи агенту, что оставил правки

Напиши в чат Монтажёра: «Я оставил комментарии на доске, прочитай и поправь». Дальше он:

1. Читает всё командой `npm run board:read -- <ролик>`: оценки, заметки, комментарии с секундой, сдвиги в пикселях, вложения, ссылки.
2. Применяет сдвиги в коде сцены и меняет то, о чём ты написал. Неясное не угадывает, а отвечает в ветке вопросом.
3. Отвечает под каждым комментарием, что именно сделал, и закрывает выполненное (`resolve`). Закрытые комментарии и сдвиги на доске приглушены.
4. Пересобирает кадры и доску. Ты смотришь новую версию.

Не согласен с результатом: нажми «Открыть снова» у комментария или сдвига и напиши, что не так. «Сводка правок» вверху собирает все правки в текст, его можно скопировать.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| Страница не открывается | Доска не запущена (после перезагрузки компьютера). Скажи агенту «запусти доску раскадровки» |
| «Порт 4321 занят» | Доска уже запущена в другом окне, либо порт занят программой. Агент запустит на другом: `npm run board:open -- --port 4322` |
| Нет досок | Доска не собрана: скажи агенту «собери доску» (`npm run frames`, потом `npm run board`) |
| `нет листа кадров` | Сначала нужны кадры: `npm run frames -- <композиция>` |
| Видео в кадре не проигрывается | Нет черновика. Выполни `npm run draft -- <композиция>`, затем `npm run board -- <композиция>` |
| У кадров вместо речи время | Нет расшифровки. Это не мешает. Добавить речь: `npm run transcribe`, потом пересобрать доску |
| Стрелка не ставится | Включи режим «↔ Сдвиг объектов» (кнопка подсвечена, курсор крестик) и тяни дольше 40 пикселей кадра |
| Ответ агента не появился | Страница сама подтягивает ответы каждые 4 секунды, пока ты не печатаешь. Обнови страницу (F5) |

## Как это устроено

- Данные доски лежат в `work/<ролик>/storyboard/`: `board.json` (кадры), `review.json` (твои правки), `frames/` (картинки кадров), `files/` (вложения), `history/` (копии `review.json` перед каждой записью), `film.mp4` (черновик для просмотра).
- В `review.json` кадра сдвиги хранятся так: `moves: [{id, from: {x, y}, to: {x, y}, label, scale, status}]`. Координаты это доли кадра от 0 до 1 от левого верхнего угла.
- Доска слушает только этот компьютер (`127.0.0.1`) и принимает запросы только со своей страницы. Чужой сайт в соседней вкладке не может подсунуть тебе комментарий.
- Команды: `npm run board -- <композиция>` собрать, `npm run board:open` запустить, `npm run board:read -- <ролик>` прочитать правки (это делает агент), `npm run board:test` проверить доску.
- Доску можно собрать и из любого готового видео: `node tools/storyboard/build-board.mjs <ролик> --video <файл.mp4>`.
