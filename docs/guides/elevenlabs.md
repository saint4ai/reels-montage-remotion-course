# ElevenLabs: озвучка для роликов без лица

Сверено 11.10.2026: страницы тарифов ElevenLabs, документация API, справка ElevenLabs. Названия кнопок личного кабинета при сверке проверить не удалось (нужен вход в аккаунт), поэтому там, где название взято не из документации ElevenLabs, стоит пометка «проверь на месте».

## Что это и зачем

ElevenLabs (elevenlabs.io) превращает текст в речь. Тебе нужен он, когда ролик идёт без твоего лица и без твоей записи: графика на весь кадр или голова-рассказчик. Сценарий уже написан, остаётся его озвучить.

Озвучивает чат «Монтаж Reels», а не ты на сайте. Он берёт текст из `work/<ролик>/SCRIPT.md`, делит на фразы, озвучивает каждую и склеивает в один файл `voice.wav`. Заодно он сам получает слова с точным временем для субтитров, расшифровка не нужна.

## Что понадобится

- Почта Google (Gmail) или любая другая для регистрации.
- Банковская карта, если берёшь платный тариф (см. ниже, зачем он нужен).
- Чат «Монтаж Reels» в папке проекта.
- Готовый и утверждённый сценарий ролика.

## Тарифы

Цены и лимиты с официальной страницы https://elevenlabs.io/pricing, открыта 11.10.2026. Акции и цифры меняются, перед оплатой сверь их на странице.

| Тариф | Цена в месяц | Кредитов в месяц | Что важно |
|---|---|---|---|
| Free | 0 $ | 10 000 | Нет коммерческой лицензии. Озвучку нельзя использовать для заработка и клиентских работ, а при некоммерческом использовании нужно указывать «elevenlabs.io» |
| Starter | 6 $ (первый месяц 1 $ по акции до 18 октября 2026) | 30 000 | Есть коммерческая лицензия, клонирование голоса Instant |
| Creator | 22 $ (первый месяц 11 $) | 121 000 | Качество звука до 192 кбит/с |
| Pro | 99 $ | 600 000 | Для больших объёмов |

Что из этого следует:

- Ролики для продвижения твоего дела это коммерческое использование. Справка ElevenLabs пишет прямо: бесплатный тариф коммерческой лицензии не даёт, платные тарифы дают («Can I publish the content I generate on the platform?», 11.10.2026). Поэтому для настоящих роликов бери **Starter за 6 $**. Бесплатный тариф подходит, чтобы попробовать голос и проверить, как всё работает.
- Бесплатный тариф закрывает часть голосов из библиотеки для запросов через API: в документации ElevenLabs сказано, что голоса Voice Library недоступны по API бесплатным пользователям (11.10.2026). Остаются стандартные голоса из списка аккаунта. Это тоже причина платить 6 $.
- Оплату и ввод карты делаешь ты сам. Какие карты принимает ElevenLabs, зависит от страны банка: проверь на странице оплаты.

## Сколько это стоит

ElevenLabs списывает кредиты за знаки текста. Сценарий на 45 секунд это 115-130 слов, около 800-900 знаков.

- Если один знак стоит один кредит, на бесплатном тарифе выходит около 11 роликов в месяц, на Starter около 33. Это ориентир: у новых моделей и в акциях расход на знак бывает другим (страница тарифов для API показывает акцию на модель eleven_v4 до 12 октября 2026).
- Настоящий расход смотри сам. Озвучь первый ролик, открой личный кабинет и посмотри, сколько кредитов списано. Агент перед озвучкой печатает число знаков (`npm run voice -- <ролик> --dry-run`), умножишь на свой расход.
- Каждая озвучка фразы тратит кредиты. Агент хранит готовые фразы в кэше: повторный запуск ничего не стоит, а при правке одного предложения он озвучивает заново только его.
- Проверка готовой озвучки распознаванием (Scribe) тоже расходует кредиты, но немного: распознаётся около минуты звука.

## Шаги

### 1. Зарегистрируйся

1. Открой https://elevenlabs.io и нажми кнопку регистрации (Sign up).
2. Войди, например, через Gmail. Пароль, код из письма и капчу вводишь ты сам.

### 2. Выбери тариф

1. Открой https://elevenlabs.io/pricing.
2. Для настоящих роликов выбери Starter (раздел «Тарифы» выше), для пробы можно остаться на Free.
3. Оплату вводишь ты сам.

### 3. Создай ключ и включи права

1. Открой https://elevenlabs.io/app/settings/api-keys (в личном кабинете это раздел Developers, вкладка API Keys: проверь на месте).
2. Нажми создание ключа (Create API Key), дай ему имя, например `montage`.
3. Права ключа. По умолчанию у ключа есть ограничения: ElevenLabs пишет, что для работы с голосами нужны Voices (read) и Text to Speech (справка ElevenLabs). Для озвучки включи три права: **Text to Speech**, **Speech to Text** и **Voices: Read**. Либо оставь ключ без ограничений. Названия переключателей проверь на месте.
4. Поставь лимит кредитов на ключ, например 5 000. Документация ElevenLabs разрешает ограничить расход каждого ключа, так что ошибка в работе не сожжёт весь тариф.
5. Скопируй ключ сразу: после закрытия окна его могут не показать снова.

### 4. Отдай ключ агенту

Это исключение из общего правила про ключи, решение владельца курса от 11.10.2026: ключ ElevenLabs вставляется прямо в чат, файл в «Загрузках» делать не нужно.

Вставь ключ в чат «Монтаж Reels» так: «Мой ключ ElevenLabs: <ключ>. Запиши его в .env и нигде не повторяй». Агент запишет его в файл `.env` в папке проекта строкой `ELEVENLABS_API_KEY=...`, проверит, что `.env` не попадает в git (он есть в `.gitignore`), и ответит одним словом «записал». Дальше ключ он нигде не покажет.

Ключ даёт доступ к твоему тарифу и тратит его кредиты. Не показывай его на скриншотах и не отправляй в публичные репозитории. Если он попал куда не надо, открой раздел с ключами, удали старый ключ, создай новый и вставь его в чат ещё раз.

### 5. Выбери голос

Голос выбираешь один раз для всего канала, чтобы ролики звучали одинаково. Агент запишет выбор в `work/_profile/brief.md`.

**Способ 1: через агента.** Напиши: «Покажи голоса моего аккаунта на русском». Агент запустит `npm run voice -- --list --lang ru` и покажет имя, пол, возраст и акцент голосов со ссылкой на образец. Открой ссылки, послушай и назови имя голоса, который понравился.

Если агент ответит, что у ключа нет права читать голоса, включи Voices: Read в настройках ключа (шаг 3) или иди вторым способом.

**Способ 2: в библиотеке на сайте.** Так видны все голоса, их можно послушать и отфильтровать по языку.

1. В левом меню нажми **Voices**, затем **Explore**.
2. Включи фильтр по языку (Language) и выбери Russian. После выбора языка появится фильтр акцента (Accent).
3. Нажми на голос, чтобы послушать образец.
4. Понравился голос: нажми на нём **+**, он попадёт в My Voices. Сохранение не занимает слоты твоих голосов.
5. Открой **My Voices**, найди голос, нажми **More actions** (три точки) и **Copy voice ID**.
6. Отправь ID агенту: «Мой голос: <ID>». ID не секрет, его можно писать в чат.

Голос из библиотеки на бесплатном тарифе по API не работает (см. раздел «Тарифы»). Остаётся выбрать стандартный голос из списка агента или перейти на платный тариф.

### 6. Озвучь ролик

Напиши в чат «Монтаж Reels»: «Озвучь сценарий ролика <название> голосом ElevenLabs». Агент сам:

1. Покажет фразы и число знаков (`--dry-run`) и спросит, продолжать ли.
2. Озвучит фразы по одной: модель eleven_v4, язык ru, цифры произносятся словами.
3. Склеит их с паузами и запишет `public/work/<ролик>/voice.wav` и слова с временем `work/<ролик>/words.json`.
4. Проверит результат распознаванием и покажет список расхождений: числа, названия сервисов, имена.

Если ElevenLabs ответит, что модели eleven_v4 нет на твоём тарифе, агент сам перейдёт на eleven_multilingual_v2 и скажет об этом. Она тоже говорит по-русски.

### 7. Послушай и поправь

1. Открой файл `public/work/<ролик>/voice.wav` и послушай от начала до конца. Особенно цифры, названия сервисов и концовку.
2. Агент покажет расхождения распознавания. Строка вида «в тексте «Claude», услышано «клод»» значит одно: Scribe записал имя по-русски. Это не всегда ошибка озвучки, но это место надо послушать.
3. Не понравилась фраза: напиши «Переозвучь фразу 4». Агент озвучит заново только её, остальные возьмёт из кэша.
4. Неверно прозвучало слово: напиши, как его надо произносить (например, имя сервиса по буквам), агент поправит текст и озвучит эту фразу заново.
5. Пауз между фразами слишком много или мало: «сделай паузы короче» (агент поставит `--pause 0.2`).
6. Принял озвучку: напиши «озвучка принята». Дальше монтаж идёт как обычно, по словам из `words.json`.

## Что нельзя

- Чужой голос без согласия человека. Клонировать можно только свой голос или голос человека, который разрешил.
- Ключ в публичные места: чат команды, скриншоты, репозиторий, описание к ролику.
- Выдавать озвучку нейросети за живую запись. В пакете на выкладку (`PUBLISH.md`) ставится метка «создано ИИ»: голос сгенерирован и звучит как настоящий.
- Бесплатный тариф для роликов, на которых ты зарабатываешь.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| «ElevenLabs не принял ключ» | Проверь строку `ELEVENLABS_API_KEY=` в `.env` (без пробелов и кавычек) или создай новый ключ (шаг 3) |
| «У ключа не хватает прав» | В настройках ключа включи Text to Speech, Speech to Text и Voices: Read |
| «Кредиты ElevenLabs закончились» | Подожди обновления лимита или повысь тариф. Готовые фразы остались в кэше, повтор не потратит их заново |
| «Этот голос недоступен на бесплатном тарифе через API» | Возьми стандартный голос из списка агента или оформи Starter |
| «Голос не найден» | Голос из библиотеки сначала добавь в My Voices (шаг 5), проверь ID |
| «Модель недоступна, перехожу на eleven_multilingual_v2» | Это нормально: озвучка пойдёт запасной моделью. Цифры и имена послушай внимательнее |
| «ffmpeg не найден» | Агент поставит ffmpeg (`npm run doctor` подскажет команду) |
| Агент пишет, что в `voice.wav` лежит чужой файл | Это твоя запись голоса. Агент не заменит её без твоего слова, сохрани копию и скажи ему «заменяй» |
| В `words.json` числа словами | Подписи взяты из произнесённого, потому что число слов не совпало. Агент поправит написание, тайминги не трогает |
