# OpenAI Platform: ключ и дешёвая модель для ассистента

Проверено по документации 10.10.2026. Страницы help.openai.com мне отдали ошибку 403, поэтому часть про оплату я знаю по результатам поиска и по странице developers.openai.com. Такие места помечены.

## Что это и зачем

OpenAI Platform это сервис, где ты получаешь доступ к моделям OpenAI для своей программы. Ассистент, который отвечает в директе, обращается к модели через API и платит за каждый запрос с предоплаченного баланса.

Не путай с подпиской ChatGPT. Подписка ChatGPT и баланс API это разные вещи и оплачиваются отдельно.

## Что понадобится

- Электронная почта.
- Страна, которую поддерживает OpenAI (см. шаг 1).
- Банковская карта (кредитная или дебетовая) для пополнения баланса. Минимум 5 долларов.
- Папка `Загрузки` на твоём компьютере для временного файла с ключом.

## Шаги

### 1. Проверь страну

Список: https://developers.openai.com/api/docs/supported-countries.

- Казахстан в списке **есть**. Кыргызстан, Узбекистан, Армения, Грузия тоже есть.
- России в списке **нет**. Беларуси тоже нет.
- Страница предупреждает: доступ из страны вне списка может привести к блокировке или приостановке аккаунта. Как оплатить из России и работает ли это, в официальных источниках, которые я открыл, не сказано. Напиши «уточни» у поддержки OpenAI. Способы обхода ограничений я не рекомендую.
- Для ошибки `403 Country, region, or territory not supported` документация отправляет к этому же списку.

### 2. Регистрация

1. Открой https://platform.openai.com (старые ссылки документации сами перенаправляют на developers.openai.com).
2. Нажми кнопку регистрации (Sign up) и создай аккаунт. Пошаговое описание экрана регистрации в официальных страницах, которые я открыл, не нашёл. Нужен ли телефон для подтверждения, тоже не нашёл.

### 3. Пополни баланс

Платформа работает на предоплате (prepaid billing).

1. Открой раздел Billing (оплата). Прямой адрес из обсуждения в сообществе OpenAI, а не из официальной справки: https://platform.openai.com/settings/organization/billing/overview.
2. Если оплаты ещё нет, нажми «Add payment details» (добавить платёжные данные) и заполни карту.
3. Нажми «Buy credits» (купить кредиты) или «Add to credit balance» (добавить на баланс). Что именно покажет кнопка, зависит от аккаунта.
4. Минимальная сумма: **5 долларов**. По умолчанию предлагается 10 долларов (справка OpenAI, данные из поиска).
5. Автопополнение (auto-reload) при первой настройке включено по умолчанию. Если не хочешь автоматических списаний, выключи его до подтверждения. Минимальная сумма автопополнения: 5 долларов.
6. После оплаты подожди несколько минут, пока баланс обновится.

Что нужно знать про деньги:

- Кредиты сгорают через 1 год после покупки. Возвраты в целом не делаются, исключения есть только для ошибок оплаты и сбоев сервиса.
- Когда баланс заканчивается, запросы падают с ошибкой `credit_balance_exhausted` (статус 429).
- Порог доверия (tier) повышается сам: чем больше ты пополнил за всё время, тем выше лимиты (см. таблицу ниже).

Как платить картой:

- По данным поиска (справка и форум): принимаются кредитные и дебетовые карты. Предоплаченные (prepaid) и виртуальные карты, как сообщают пользователи, не принимаются. Это не прочитано мною на официальной странице. Проверь свою карту на пробной оплате минимальной суммы.
- Карта казахстанского банка пройдёт ли: в официальных страницах, которые я открыл, ответа нет. Напиши «уточни» в банке или у поддержки OpenAI.
- Карты российских банков: см. шаг 1, «уточни».

### 4. Поставь ограничение расходов

Это защита от случайного большого счёта.

1. Открой Settings → Organization → Limits (настройки → организация → лимиты). Путь взят с официальной страницы про лимиты.
2. Установи оповещение (spend alert) на сумму в долларах и жёсткий месячный лимит (hard limit). Жёсткий лимит останавливает запросы, когда расход достиг заданной суммы. Для начала подойдёт 10 долларов.

Что именно как называется на экране, я не видел. Ориентируйся на слова «spend alert» и «hard limit» из документации.

### 5. Создай ключ

1. Открой https://platform.openai.com/settings/organization/api-keys.
2. Нажми «Create new secret key» (создать новый секретный ключ). В быстром старте кнопка названа «Create an API Key». Подпись зависит от версии экрана.
3. Заполни поля. По данным справки OpenAI (из поиска) порядок такой: имя (Name), проект (Project), права (Permissions).
   - Имя: например `assistant`.
   - Проект: лучше создать отдельный проект под ассистента, чтобы его расход было видно отдельно. Без выбора проекта кнопка создания может быть неактивна.
   - Права: **All** (все права, по умолчанию) самый простой вариант. **Restricted** (ограниченные) позволяет выбрать права по разделам. **Read only** (только чтение) для ассистента не подойдёт, он должен отправлять запросы. Какие именно галочки нужны для варианта Restricted, я не проверил. Начни с All.
   - Срок действия: в документации по безопасности рекомендуют задавать срок действия ключа и периодически менять ключ.
4. Скопируй ключ сразу и сохрани по правилу из раздела «Куда положить ключ». Покажет ли панель ключ повторно, в документации, которую я открыл, не сказано. Если потеряешь, просто создай новый.

Ключ это секрет. Его нельзя вставлять в программу, которая работает в браузере или в телефоне пользователя. Хранится он только на сервере, в переменной окружения (у OpenAI она называется `OPENAI_API_KEY`).

### 6. Проверь ключ

Это делает агент, тебе ничего вводить не нужно. Он выполняет запрос списка моделей:

```
curl https://api.openai.com/v1/models -H "Authorization: Bearer $OPENAI_API_KEY"
```

Если пришёл список моделей, ключ рабочий. Ошибка `401` значит, что ключ неверный. Сам ключ агент в чат не печатает.

Выбранный сервер и модель агент затем указывает в программе ассистента. Рекомендация документации OpenAI: использовать Responses API (новый вход), а не старый Chat Completions.

## Какая модель подходит для ответов в директе

Цены со страницы https://developers.openai.com/api/docs/pricing, стандартный режим, за 1 миллион токенов (токен это примерно часть слова). Дата проверки: 10.10.2026. На самой странице даты обновления нет.

| Модель | Вход | Вход из кэша | Выход | Кому подходит |
|---|---|---|---|---|
| `gpt-6-luna` | 0,10 $ | 0,01 $ | 0,50 $ | Основной выбор. По описанию OpenAI: «самая эффективная модель для сфокусированных задач с большим объёмом» |
| `gpt-5.6-luna` | 0,20 $ | 0,02 $ | 1,20 $ | Запасной вариант, если у первой не получится, описана как «оптимизирована для задач, где важна цена» |
| `gpt-6.1-sol` | 2,00 $ | 0,10 $ | 10,00 $ | Если нужен ответ умнее (сложные вопросы). В 20 раз дороже по входу, чем `gpt-6-luna` |

Что важно:

- `gpt-6-luna` поддерживает вызов функций и структурированные ответы, окно 1 050 000 токенов, знания до 18 мая 2026. Поддерживает русский язык или нет, в документации прямо не сказано. Проверь на 10 тестовых диалогах до запуска.
- Для вызова функций в старом Chat Completions у `gpt-6-luna` нужно поставить `reasoning_effort` в значение `none`. В Responses API этого ограничения на странице модели нет.
- Режимы Batch и Flex вдвое дешевле стандартного, но они для отложенной обработки, а не для живого ответа в чате.
- Мой расчёт для понимания масштаба: ответ на одно сообщение, около 2 000 токенов входа и 300 токенов выхода, на `gpt-6-luna` стоит примерно 0,00035 доллара. 1 000 ответов это примерно 35 центов. Реальные цифры зависят от длины переписки.

### Уровни и лимиты

С официальной страницы про лимиты (developers.openai.com/api/docs/guides/rate-limits):

| Уровень | Как получить | Лимит расходов в месяц |
|---|---|---|
| Free | находиться в разрешённой стране | 100 $ |
| Build | пополнить в сумме на 5 $ | 500 $ |
| Launch | пополнить в сумме на 100 $ | 5 000 $ |
| Grow | пополнить в сумме на 500 $ | 200 000 $ |

Свои лимиты по моделям смотри в Settings → Organization → Limits. Для `gpt-6-luna` на уровне Build указано 5 000 запросов в минуту и 2 000 000 токенов в минуту. Для ассистента одного эксперта этого более чем достаточно. Уровень повышается сам, когда сумма пополнений достигает следующего порога.

## Куда положить ключ

Правило одно для всех сервисов. Ключ никогда не вставляй в чат с агентом.

1. Скопируй ключ из панели сервиса.
2. Открой Блокнот, вставь ключ и сохрани файл `Загрузки\<сервис>-key.txt`. Здесь `<сервис>` это короткое имя сервиса, например `zernio`.
3. Напиши агенту только это: «Ключ лежит в файле Загрузки\<сервис>-key.txt». Само значение не пиши.
4. Агент сам прочитает файл и положит значение в переменную окружения или в файл `.env` на сервере. На экране он значение не показывает.
5. После этого агент удаляет файл `Загрузки\<сервис>-key.txt`. Проверь сам, что файла в Загрузках больше нет.
6. Если ключ всё-таки попал в чат, скриншот или публичный репозиторий, сразу удали его в панели сервиса и создай новый.

Для этой инструкции файл называется `Загрузки\openai-key.txt`, а на сервере переменная называется `OPENAI_API_KEY`. Если ключ утёк, на странице ключей удали его и создай новый: отозванный ключ перестаёт работать через несколько секунд.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| `401 Incorrect API key provided` | В ключе опечатка или лишний пробел, ключ удалён или принадлежит другому проекту. Создай новый ключ и замени |
| `403 Country, region, or territory not supported` | Запрос идёт из страны вне списка. Проверь список стран (шаг 1) |
| `429 Credit balance exhausted` (`credit_balance_exhausted`) | Закончились предоплаченные кредиты. Пополни баланс в Billing |
| `429 Organization spend limit reached` или `Project spend limit reached` | Достигнут твой же месячный лимит расходов. Подними лимит в Limits или подожди нового месяца |
| `429 Rate limit reached for requests` | Слишком много запросов. Агент должен подождать время из `Retry-After`, потом повторить |
| `500` или `503 Model temporarily overloaded` | Проблема на стороне OpenAI. Повтори позже, проверь статус-страницу |
| Нет кнопки «Add to credit balance» | В некоторых старых аккаунтах предоплата ещё не включена. Так пишут в сообществе, это не официальный текст. Проверь страницу Billing или напиши в поддержку |
| Карту не принимают | Возможно, это prepaid или виртуальная карта. Попробуй обычную дебетовую карту банка, затем спроси поддержку |
