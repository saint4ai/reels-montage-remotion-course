# Claude Desktop: приложение с агентом Claude Code

Сверено с официальной документацией Anthropic на 10.10.2026. Где факт в документации не подтверждён, стоит пометка «проверь на месте».

## Что это и зачем

Claude Desktop это программа для компьютера от Anthropic. В ней три вкладки: **Chat** (обычный разговор), **Cowork** (автономные задачи в фоне) и **Code** (Claude Code, агент, который работает с файлами на твоём компьютере).

Нужна именно вкладка **Code**. В ней агент ведёт тебя по шагам, создаёт файлы, заходит на сервер и настраивает ассистента. Терминал для этого не обязателен: Claude Code уже встроен в приложение.

## Что понадобится

- Компьютер с Windows (версия x64 или ARM64) или macOS. Для Linux есть бета.
- Страна из списка поддерживаемых Anthropic. **Казахстан в списке есть. России в списке нет**. Платные планы доступны только людям, которые физически находятся в поддерживаемой стране, и регистрация требует телефон из поддерживаемой страны. Бесплатная версия имеет то же условие. Список: https://www.anthropic.com/supported-countries. Способы обойти ограничения не используй.
- Платная подписка **Pro, Max, Team или Enterprise**. На бесплатном тарифе вкладка Code недоступна. Если без подписки нажать Code, приложение предложит оформить платный план.
- Банковская карта (кредитная или дебетовая). Для оплаты на сайте принимаются только карты; подойдёт ли карта твоего банка, проверь при оплате. Подписка через приложения iOS и Android оплачивается через App Store или Google Play.
- Папка для проекта на компьютере.
- Для режима «изолированная копия» (worktree): установленный Git. На Windows это Git for Windows (git-scm.com/downloads/win).

## Шаги

### 1. Установи приложение

1. Открой https://claude.com/download (адрес claude.ai/download перенаправляет туда).
2. Нажми «Download» рядом с Windows. Есть отдельная кнопка для Windows ARM64, значок Microsoft Store и вариант для macOS. Для Linux кнопка «See docs».
3. Запусти скачанный установщик и дождись конца.
4. Открой Claude из меню «Пуск» и войди своим аккаунтом Anthropic. Адрес для регистрации и входа: https://claude.ai.

Системные требования приложения на странице загрузки не перечислены. Там написано смотреть Help Center.

### 2. Оформи подписку

Цены с https://claude.com/pricing на 10.10.2026. Страница пишет «$» без кода валюты (скорее всего, доллары США), цены без налогов, и может меняться без предупреждения.

| План | Цена | Claude Code входит |
|---|---|---|
| Free | 0 $ | нет |
| **Pro** | **20 $ в месяц** при оплате помесячно, или 17 $ в месяц при оплате за год сразу (200 $) | да |
| Max | от 100 $ в месяц | да |
| Team (стандартное место) | 25 $ в месяц за место помесячно, 20 $ при оплате за год | да |

Для начала хватит Pro.

Как оформить Pro (справка Anthropic):

1. Открой https://claude.ai, введи почту и нажми «Continue with email» (или «Continue with Google»).
2. Нажми на свои инициалы или имя внизу слева и выбери «Settings».
3. Перейди в Settings → Billing и нажми «Upgrade plan».
4. Нажми «Get Pro plan».
5. Выбери помесячную или годовую оплату.
6. Введи данные карты и нажми «Subscribe».

Что важно знать:

- Лимиты использования у Pro и Max общие для чата и для Claude Code. Есть лимит на 5 часов и недельный лимит.
- Подписка продлевается автоматически, отменить можно в любой момент.
- Не задавай в компьютере переменную окружения `ANTHROPIC_API_KEY`, если хочешь работать по подписке. Если она задана, Claude Code использует её вместо подписки, и тогда деньги списываются по тарифам API.

### 3. Открой вкладку Code

1. Нажми вкладку **Code** вверху по центру.
2. Если приложение предлагает «upgrade», значит, подписки ещё нет. Оформи её (шаг 2).
3. Если предлагает войти онлайн, пройди вход в браузере и перезапусти приложение.
4. Если видишь ошибку 403, см. таблицу ошибок.

### 4. Выбери папку проекта и запусти первую сессию

Перед первым сообщением в нижней части окна задаются четыре вещи:

1. **Environment** (среда): выбери **Local**, это значит, что агент работает на твоём компьютере с твоими файлами. Есть ещё Cloud (в облаке), SSH (на удалённом компьютере) и WSL (на Windows).
2. **Project folder** (папка проекта): нажми **Select folder** и выбери папку проекта. Лучше создай для ассистента отдельную чистую папку, например `Документы\assistant`.
3. **Model** (модель): выбери в списке рядом с кнопкой отправки.
4. **Permission mode** (режим разрешений), список рядом с кнопкой отправки:
   - **Manual**: агент спрашивает перед правкой файлов и запуском команд. Для новичка самый безопасный вариант.
   - **Accept edits**: правки файлов принимаются сами.
   - **Plan**: агент только предлагает план и ничего не меняет.
   - **Auto**: специальная проверка в фоне блокирует рискованные действия вместо того, чтобы спрашивать тебя.

   (Раньше режимы назывались Ask permissions, Auto accept edits и Plan mode.)

Напиши задачу и нажми **Enter**. Остановить агента можно кнопкой остановки или клавишей `Esc`. Исправление можно написать прямо во время работы и отправить Enter.

### 5. Открой новую сессию в той же папке

Сессия это отдельный разговор со своей историей и своей папкой проекта.

1. Нажми **+ New session** в боковой панели. Или нажми **Ctrl+N** (в Windows).
2. В новой сессии снова выбери **Local** и **Select folder**, и выбери ту же самую папку. Проверь на месте: приложение может не запомнить прошлую папку.
3. Между сессиями переключайся через боковую панель или `Ctrl+Tab` и `Ctrl+Shift+Tab`.
4. Чтобы видеть две сессии рядом, зажми `Ctrl` и кликни вторую сессию в боковой панели. Закрыть панель: `Ctrl+\`.
5. Если проект это Git-репозиторий, рядом с названием ветки есть пункт **worktree**. С ним сессия получает свою изолированную копию проекта, и две сессии не мешают друг другу. Копии лежат в `папка-проекта\.claude\worktrees\`. Убрать копию можно: наведи на сессию в боковой панели и нажми значок архива.
6. Без worktree две сессии в одной папке меняют одни и те же файлы. Не давай обеим сессиям править одни файлы одновременно.
7. Если пишет «Git is required» (нужен Git), установи Git for Windows или обнови приложение. В версиях Claude Desktop до 1.49585.0 Git требовали даже для простой сессии.

Если Claude сам предлагает отдельную задачу, он показывает «чип» с задачей. Нажмёшь на него, и задача откроется в новой сессии с отдельной копией проекта.

Полезные клавиши (Windows): `Ctrl+/` список всех клавиш, `Ctrl+N` новая сессия, `Ctrl+W` закрыть сессию, `Ctrl+Shift+B` браузер, `Ctrl+Shift+D` панель с правками, ``Ctrl+` `` (клавиша с обратной кавычкой) терминал.

### 6. Встроенный браузер

В приложении есть панель **Browser** (браузер). В ней агент показывает запущенные программы и может открывать сайты.

- Открыть: `Ctrl+Shift+B`, или кнопка **Browser** в заголовке сессии.
- Это обычный браузер с вкладками. В нём можно открыть документацию или панель сервиса рядом с чатом.
- Он использует **чистый профиль**: твоих паролей, закладок и истории нет. Входить на сайты в нём нужно самому. Окна входа, в том числе через Google, работают.
- Агент не покупает товары, не создаёт аккаунты и не обходит капчу без тебя. Первый раз на новом сайте он спрашивает разрешение: **Allow once**, **Always allow** или **Deny**.
- При первом клике по ссылке из чата приложение спросит, открывать ли ссылки во встроенном браузере или в браузере по умолчанию. Позже это меняется в меню **⋮** панели: пункт **Open links in built-in browser**.
- В меню **⋮** есть **Keep cookies** (сохранять входы после выхода), **Clear browsing data** (очистить данные) и **Auto-verify changes** (автопроверка правок).
- Выключить браузер совсем: Settings → Claude Code → **Browser tools**.

Для курса это значит: входить в панели Zernio, OpenAI, провайдера сервера ты будешь **сам**, в этом окне или в своём браузере. Агент пароли не вводит.

**Чем встроенный браузер отличается от расширения Claude in Chrome.** Расширение Claude in Chrome работает в твоём обычном Chrome и использует твои входы на сайтах (Gmail, Google Docs и т. д.). Оно нужно, когда агент должен действовать от твоего имени в уже открытых аккаунтах.

- Требования: браузер Google Chrome (справка Anthropic пишет, что другие браузеры на Chromium не поддерживаются; документация Claude Code пишет, что подходят также Edge и другие, это противоречие, ориентируйся на Chrome), расширение версии 1.0.36 или выше, платный план (Pro, Max, Team, Enterprise).
- Установка: в Chrome Web Store найди Claude in Chrome, нажми «Add to Chrome», войди аккаунтом Claude и закрепи расширение значком булавки.
- Подключение к Claude Desktop (справка Anthropic): нажми инициалы внизу слева → «Settings» → «Connectors» → найди «Claude in Chrome», нажми «Configure» → включи переключатель. По умолчанию он выключен и включается отдельно для каждого разговора в чате.
- Проверь на месте, работает ли расширение внутри вкладки Code: команды `claude --chrome` и `/chrome` описаны в документации для терминала и VS Code.

### 7. Подключить MCP-инструмент (например, Zernio)

Подробно написано в `zernio.md`, раздел 7. Коротко: в Desktop серверы MCP читаются из тех же настроек, что и в терминале (`~/.claude.json` и файл `.mcp.json` в папке проекта). Во вкладке Code отдельной команды `claude` может не быть (приложение содержит собственную копию Claude Code). Поэтому проще положить в папку проекта файл `.mcp.json`. Также есть раздел **Customize** → **Connectors**, где добавляется свой коннектор по адресу.

### 8. Обновление

Приложение само обновляется при запуске. Проверить вручную в Windows: меню **Help → Check for Updates**, затем начни новую сессию. Вкладка Code работает на собственной копии Claude Code со своим номером версии, он может отличаться от `claude` в терминале.

## Куда положить ключ

Правило одно для всех сервисов. Ключ никогда не вставляй в чат с агентом.

1. Скопируй ключ из панели сервиса.
2. Открой Блокнот, вставь ключ и сохрани файл `Загрузки\<сервис>-key.txt`. Здесь `<сервис>` это короткое имя сервиса, например `zernio`.
   Имена файлов одни на весь курс: `zernio-key.txt`, `openai-key.txt`, `openrouter-key.txt`, `telegram-bot-key.txt`, `server-key.txt`, `google-sheets-key.txt`, `elevenlabs-key.txt`, `higgsfield-key.txt` (если ключ нужен).
3. Напиши агенту только это: «Ключ лежит в файле Загрузки\<сервис>-key.txt». Само значение не пиши.
4. Агент сам прочитает файл и положит значение в переменную окружения или в файл `.env` на сервере. На экране он значение не показывает.
5. После этого агент удаляет файл `Загрузки\<сервис>-key.txt`. Проверь сам, что файла в Загрузках больше нет.
6. Если ключ всё-таки попал в чат, скриншот или публичный репозиторий, сразу удали его в панели сервиса и создай новый.

В этой инструкции ключей нет: Claude Desktop входит через браузер аккаунтом Anthropic. Если когда-то получишь ключ API Anthropic, сохраняй его по этому же правилу, но помни про `ANTHROPIC_API_KEY` (шаг 2): он перебивает подписку.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| При нажатии на Code предлагают оформить план (upgrade) | Нужна платная подписка Pro, Max, Team или Enterprise. Оформи её (шаг 2) |
| Предлагают войти онлайн | Пройди вход в браузере и перезапусти приложение |
| `Error 403: Forbidden` во вкладке Code | 1) Выйди из аккаунта в меню приложения и войди снова. 2) Проверь, что подписка активна. 3) Закрой приложение полностью (не только окно) и открой снова. 4) Проверь интернет и прокси |
| Пустой или зависший экран при запуске | Перезапусти приложение, проверь обновления. На Windows посмотри журнал в Просмотре событий: Журналы Windows → Приложение |
| `Failed to load session` | Папка могла исчезнуть или нет прав. Выбери другую папку или перезапусти приложение |
| «Git is required» | Установи Git for Windows или обнови приложение до версии 1.49585.0 и выше |
| Агент не находит `npm`, `node` и другие программы | Проверь, что они работают в обычном терминале, и перезапусти приложение |
| Переключатели MCP-серверов не реагируют (Windows) | Проверь настройки сервера, перезапусти приложение, посмотри процесс в Диспетчере задач |
| Подписка есть, а списывает как за API | В системе задана переменная `ANTHROPIC_API_KEY`. Удали её |
| Страна не поддерживается, регистрация не проходит | Anthropic работает только в списке стран. Это условие аккаунта, обойти его документация не предлагает |
