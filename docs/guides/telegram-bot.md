# Telegram-бот для заявок (через @BotFather)

Проверено по документации 10.10.2026 (core.telegram.org/bots).

## Что это и зачем

Это твой собственный бот в Telegram. Когда ассистент находит в переписке заявку, он присылает её в твой личный чат или в группу с командой: имя, контакт, о чём человек просил.

Это отдельная вещь от подключения Telegram в Zernio (`zernio.md`). Там работает бот Zernio. Здесь бот твой, и он только присылает тебе уведомления.

## Что понадобится

- Аккаунт Telegram и приложение (телефон или компьютер).
- Куда слать заявки: твой личный чат с ботом или группа, где ты и коллеги.

## Шаги

### 1. Создай бота

1. В Telegram найди **@BotFather** (ссылка t.me/botfather). Ищи по точному имени и открой чат.
2. Отправь команду `/newbot`.
3. BotFather спросит **имя** (name). Оно показывается в контактах. Можно по-русски и с пробелами, например «Заявки Анна».
4. Затем спросит **имя пользователя** (username). Правила из документации: от 5 до 32 символов, только латинские буквы, цифры и подчёркивание, и обязательно с окончанием `bot`, например `anna_leads_bot`. Если имя занято, придумай другое. Изменить username потом **нельзя**, выбирай внимательно.
5. BotFather пришлёт **токен**. Он выглядит как `123456789:AAxxxxxxxx…` (цифры, двоеточие, длинная строка из букв и цифр). Это условный пример формата, не настоящий токен.

Токен это пароль от бота. Кто получил токен, тот полностью управляет ботом. Не показывай его никому, кроме своего агента: ему токен нужен, ты вставишь его в чат (шаг 2).

### 2. Отдай токен агенту

Вставь токен в чат по правилу из раздела «Как отдать ключ агенту» ниже. Файл в «Загрузках» делать не нужно.

### 3. Нажми «Start» у бота

Бот не может написать человеку первым. Сначала пользователь должен сам написать боту или добавить его в группу.

1. Открой своего бота в Telegram (по username).
2. Нажми кнопку **Start** (при первом открытии чата Telegram показывает её). Если кнопки нет, отправь `/start`.

Без этого шага бот не сможет прислать тебе личное сообщение.

### 4. Узнай chat_id

`chat_id` это числовой адрес чата, куда бот будет писать. Секретом он не является.

**Личный чат (с тобой).** После шага 3 попроси агента: «Узнай мой chat_id». Агент сам запросит у Telegram последние сообщения бота (метод `getUpdates`) и найдёт в ответе число в поле `chat.id`. Токен при этом нигде не печатается.

**Группа.**

1. Добавь бота в группу (шаг 5).
2. В группе напиши сообщение, которое бот увидит. По умолчанию бот в группе видит только команды и сообщения, адресованные ему (режим приватности включён). Поэтому напиши команду в таком виде: `/start@username_бота`. Либо сделай бота администратором группы: администраторам бот получает все сообщения.
3. Попроси агента: «Узнай chat_id группы». Он снова вызовет `getUpdates` и найдёт `chat.id` группы.
4. Номер группы обычно **отрицательный**, например `-4012345678`. У супергрупп он начинается на `-100`. Минус входит в число, копируй его целиком. Прямого пояснения про минус и `-100` в официальной документации Telegram нет, оно есть в сторонних инструкциях. В документации сказано только, что идентификатор чата это целое число, до 52 значащих бит.

Важно: `getUpdates` перестаёт работать, если для бота включён вебхук. Для уведомлений вебхук боту не нужен, поэтому не включай его.

### 5. Добавь бота в группу

В документации Telegram есть только один способ, описанный подробно: ссылка с параметром `startgroup`. Она предлагает выбрать группу, куда добавить бота. Ссылка выглядит как `https://t.me/username_бота?startgroup=true`. Какое значение ставить после знака равенства, документация не уточняет. Обычно ставят любое слово, например `true`.

Обычный способ через приложение (из практики, в документации Telegram его пошагового описания нет): открой группу, нажми на её название вверху, выбери «Добавить участника» (Add member), найди бота по username и добавь.

Админом бота делать не обязательно, если он только отправляет сообщения. Но тогда чтобы узнать `chat_id`, нужна команда с `@` или права администратора (см. шаг 4).

### 6. Проверь отправку

Попроси агента отправить тестовое сообщение в этот чат (метод `sendMessage` с `chat_id` и `text`). Если оно пришло, всё работает. Запрос идёт на адрес `https://api.telegram.org/bot<токен>/sendMessage`, токен подставляет агент, ты его не видишь.

### 7. Если токен утёк

В чате с @BotFather отправь `/token`, выбери бота. По документации эта команда выдаёт новый токен, если старый скомпрометирован или потерян. После этого повтори шаг 2 с новым токеном. Через команду `/mybots` можно открыть список своих ботов.

## Как отдать ключ агенту

Вставь ключ в чат одним сообщением: «Мой ключ Telegram-бота: <ключ>. Запиши его в .env и нигде не повторяй». Файл в «Загрузках» делать не нужно (решение владельца курса, 11.10.2026).

Агент запишет значение в файл `assistant/.env` строкой `TELEGRAM_BOT_TOKEN=…`, проверит, что файл не попадает в git, и ответит одним словом «записал». Дальше он ключ нигде не покажет. Здесь «ключ» это токен бота от BotFather. `chat_id` секретом не является, его можно написать в чат открыто.

Общее правило для всех сервисов и что в чат вставлять нельзя: [claude-desktop.md](claude-desktop.md), раздел «Как отдать ключ агенту».

## Частые ошибки

| Что видно | Что делать |
|---|---|
| Бот не присылает личные сообщения | Ты не нажал Start у бота. Открой чат с ботом и нажми Start |
| `getUpdates` возвращает пустой список | Напиши боту новое сообщение и повтори. Если у бота включён вебхук, `getUpdates` не работает. В группе пиши `/start@username_бота` или сделай бота администратором |
| Не могу найти @BotFather | Проверь точное написание `@BotFather` и открой ссылку t.me/botfather |
| «Username is already taken» (имя занято) | Придумай другой username с окончанием `bot` |
| Username нельзя изменить | Так устроено в Telegram. Если очень надо, создай нового бота через `/newbot` |
| Токен попал в чат или на скриншот | Отправь @BotFather `/token`, получи новый токен и вставь его в чат по правилу выше |
| В группе бот не отвечает на сообщения | Режим приватности: бот видит только команды и обращения к нему. Дай боту права администратора. Меняется режим командой `/setprivacy` у @BotFather, но после этого бота нужно удалить из группы и добавить заново |
| chat_id группы без минуса не работает | Номер группы отрицательный. Копируй вместе с минусом |
