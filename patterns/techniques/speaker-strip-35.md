# Упаковка спикера: полоса 35% внизу

Основной формат для альбомной (горизонтальной) записи: спикер внизу кадра полосой во всю высоту под графикой, в любой
стилистике. Выбран автором курса 03.10.2026 из сравнения трёх высот, уточнён 05.10.2026 под обрезку Instagram.
Код: `src/kit/strip.tsx`, `<SpeakerStrip src={REC} srcW=… srcH=… h={STRIP.h35} inset={STRIP.insetIg} r={STRIP.rIg} />`.
Правило обрезки Instagram подробно: `patterns/techniques/instagram-viewport-guard.md`.

## Как устроено (кадр 1440×2560)

- Полоса **900 px, 35% высоты**, y 1660…2560.
- Ширина **1180 px, x 130…1310**: уже кадра на 130 px с каждого бока. Верхние углы скруглены **радиусом 110**, низ ровный по кромке кадра, пустоты под спикером нет.
- Запись заполняет полосу без растягивания: у 16:9 лишнее срезается по бокам, лицо целиком, по вертикали ставится по лицу.
- Голова: `headTop` это доля высоты записи, где макушка в самый высокий момент ролика (замер по кадрам), над ней `headroom` 80 px воздуха. `zoom 1.3` без этого замера срезает верх головы.
- Если запись снята на телефон вертикально, а внутри горизонтальная картинка с чёрными полосами, сначала вырезать картинку (`ffmpeg -vf cropdetect`), потом ставить по тем же правилам.
- Графика, текст и субтитры над полосой, нижняя граница графики около y 1600, субтитры по центру на y 1540. На полосу заходит только фон: описание и ник Instagram ложатся на неё.
- Лёгкая тень вверх и тонкий блик по верхней кромке, чтобы край читался на белом и на тёмном фоне.

## Правка 05.10.2026: полоса уже, радиус шире

Instagram растягивает 9:16 по высоте окна и срезает бока: на вкладке Reels по 68 px с каждого бока кадра 1440, во весь
экран по 130 px (замер по скриншотам iPhone 1290×2796). Радиус 56 при полосе во всю ширину оказывался целиком в срезанной
зоне, углы на телефоне не были видны. Поэтому: полоса x 130…1310 с радиусом 110, графика и субтитры x 160…1280.

Проверка до показа: ключевые кадры в трёх видах (исходник, срез 68 и 130 px с боков). Во всех видах видны углы полосы, ни
один заголовок, логотип или карточка не обрезаны.

## Вариант «голова поверх края» (необязательный)

Запись в карточке, верх карточки опущен ниже середины головы (y 2000), а над краем рисуется только вырезанный силуэт
головы с мягкой тенью: голова выходит за рамку на фон ролика. Нужна отдельная запись с прозрачностью (WebM VP9), силуэт
вырезает инструмент вырезки фона, например RobustVideoMatting; в курс он не входит. Параметры `cut` и `cardTop` у
`SpeakerStrip`. Порядок слоёв важен: карточка с записью, затем силуэт над краем с тенью, затем тот же силуэт внутри карточки.
Если силуэт с тенью рисовать последним, тень ложится поясом поперёк лица; если внутри карточки оставить исходную запись, на краю виден шов.
Перед показом проверять кадры в зоне y 1450…2560 на светлом и тёмном фоне: нет остатков кресла у ушей, нет шва по краю.
