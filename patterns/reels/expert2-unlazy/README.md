# Unlazy: «Claude пишет «готово», а проверки не пройдены» (ЭКСПЕРТ)

Стиль ЭКСПЕРТ, вариант «доска»: платиновая доска сверху, запись спикера на нижней половине, субтитры тёмной плашкой на шве. Видео работы сервиса нет, поэтому алгоритм показан схемами, а настоящая только карточка репозитория.

- Карта монтажа и решения: `DIRECTION.md`. Описание стиля: `patterns/styles/expert/PATTERN.md`.
- Код: `src/reels/rm/r39/Reel.tsx`, общий каркас `src/reels/rm/bExpert.tsx`. Композиция для студии Remotion: `Expert2-Unlazy`.
- Кадры готового ролика: `frames.jpg`.

Что не входит в курс. Запись спикера (вертикальная 1080×1920, голос берётся из неё же) в репозитории не лежит. Композиция рендерится с заглушкой вместо лица (студийный фон и микрофон) и без голоса. Чтобы собрать свой ролик, положи запись в `public/work/<slug>/` и впиши путь в поле `src` константы `REC` в начале `src/reels/rm/r39/Reel.tsx`; размеры записи и доля `faceTop` лежат рядом. Карточка репозитория, снимок README и 3D-планшет лежат в `public/rm/r39`.
