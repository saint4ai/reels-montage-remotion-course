# Unlazy (ЭКСПЕРТ v2): карта монтажа

Ролик про скилл Unlazy, который заставляет агента записывать проверки до работы и засчитывать «готово» только после их прохождения. 46,9 с, 60 к/с, кадр 1440×2560. До перемонтажа ролик был в стиле Scene × ЛИСТ (3,1 тыс. просмотров). Теперь стиль ЭКСПЕРТ: платиновая доска сверху, запись автора внизу.

## Раскладка (кадр 1440×2560)

- Доска 1280 px сверху. Графика в y 250…1080, в x 150…1290.
- Запись вертикальная 1080×1920 занимает нижнюю половину (1440×1280, y 1280…2560). Окно записи от 22% до 72% её высоты: голова целиком с запасом сверху.
- Субтитры одной строкой тёмной плашкой на шве, центр y 1175. Числа цифрами (2, 3, 7 000), «Claude Code» вместо ошибки распознавания.
- Акценты: оранжевый #FF7A2F и мятный #3DEDC3. Красный только для «шаг не выполнен».
- Хук с кадра 0: огромное «Подтвердились».
- Переходы по очереди: размытие через цвет и рывок вбок.

## Из материалов

Использованы карточка репозитория (настоящая), снимок README и знаки Claude, OpenAI, Anthropic, GitHub из `public/brand`. Видео работы сервиса не нашлось ни в первой версии, ни в этой, поэтому вместо терминала схемы. Знака AMD в наборе нет, название дано только текстом. Картинка 3D-планшета с галочками не использована: стиль держится на белых карточках и настоящих снимках, объект нужен стилю ЛИСТ. Если понадобится объект в финале «Готово», его можно положить на правый край карточки «Шаг 3».

## Устройство сцены

- Заголовок на всю ширину доски, который объявляет мысль блока.
- Под ним одна визуальная метафора: карточка, плитка, таймер, счётчик или сетка. Никакого терминала, которого нет в материалах.
- Одна или две пилюли на ключевых словах: они добавляют вывод («сама признала», «не показалось», «так выглядит «готово»»), а не пересказывают речь.
- Длина сцены равна длине мысли: от 1,5 до 7 секунд, девять сцен на 47 секунд.

## Звук и голос

Голос идёт из самой записи, картинка записи без звука. Эффекты из `public/sfx` на громкости ×0,37 привязаны к действиям: появление карточки, галочка, счётчик, стык. Мастеринг до −14 LUFS делается после рендера.

## Главные приёмы

- Заголовок сцены меняется на ключевом слове («Полчаса работает» → «Пишет «Готово»»), а не просто сменяется следующим. Зритель видит момент, где ломается ожидание.
- Счётчики и таймеры считают в реальном времени речи: 00:00 → 30:00, 0/3 → 3/3, 0 → 7 000.
- Чек-лист закрывается галочками по очереди под слова: визуально «готово» наступает только после всех проверок.
- Новостные утверждения остаются словами автора записи, цифра «7 000 сессий» подписана как из аудита AMD.

## Чему учит этот ролик

1. Хук с кадра 0: одно огромное слово («Подтвердились»), мелкого текста в первые 3 с нет.
2. Нет видео сервиса, не выдумывай терминал: покажи алгоритм схемой, а настоящим оставь только то, что есть (карточка репозитория).
3. Один блок, один заголовок, одна мысль. Пилюли на словах добавляют вывод («не показалось», «так выглядит «готово»»), а не пересказывают речь.
4. Красный один на весь ролик со смыслом «шаг не выполнен», мятный со смыслом «готово». Цвет нельзя тратить на украшение.
5. Каждый стык чередуй по очереди: размытие через цвет и рывок вбок. Чередование задаёт ритм без лишней суеты.
6. Утверждения из новостей подписывай источником и оставляй словами автора, а не фактами от лица ролика.

## Чего не повторять при переносе

- Схемы Unlazy (уровни усилия, чек-листы, сетка сессий): это карта про эту тему.
- Набор из девяти сцен и порядок стыков: каждый новый ролик получает свою карту.
- Тайминги и тексты пилюль привязаны к словам этой записи.
