# Деньги: 4 бесплатных коннектора (ЭКСПЕРТ, платиновая доска)

Стиль ЭКСПЕРТ, вариант «доска»: запись спикера на всю нижнюю половину кадра, сверху платиновая доска с отдельным разделом на каждый коннектор, снимки сервисов в окнах браузера.

- Карта монтажа и решения: `DIRECTION.md`. Описание стиля: `patterns/styles/expert/PATTERN.md`.
- Код: `src/reels/rm/r20/Reel.tsx`, общий набор стиля `src/reels/rm/expertBoardKit.tsx`, движок `src/styles/engine.tsx`. Композиция для студии Remotion: `Expert2-Money`.
- Кадры готового ролика: `frames.jpg`.

Что не входит в курс. Запись спикера (вертикальная 1080×1920, голос берётся из неё же) и запись экрана Pipeboard (`PIPEBOARD_CLIP`) в репозитории не лежат. Композиция рендерится с заглушкой вместо лица (студийный фон и микрофон) и без голоса, а в окне Pipeboard стоит плитка сервиса. Чтобы собрать свой ролик, положи запись в `public/work/<slug>/` и впиши путь в константу `REC` в начале `src/reels/rm/r20/Reel.tsx`; если у тебя есть запись экрана сервиса, положи её в `public/rm/r20/pipeboard.mp4` и переключи `PIPEBOARD_CLIP` на `true`. Страницы GitHub и дашборд Metabase лежат в `public/rm/r20`, логотипы в `public/brand`.
