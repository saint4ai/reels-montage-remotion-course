# Codenotch: остаток лимитов ИИ

запись экрана приложения + подписи, Mac и Windows.

- Карта монтажа и решения: `TZ.md`.
- Код: `code/` (Reel.tsx, words.ts и помощники). Это образец метода: блоки и приёмы брать, набор сцен целиком не переносить.
- Кадры готового ролика: `frames.jpg` (нет).

Записи и картинки ролика в репозиторий не входят: код ссылается на `public/r2x/...`. Чтобы запустить, подставь свои файлы в `public/work/<slug>/` и поправь пути.
