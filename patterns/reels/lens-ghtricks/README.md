# Трюки со ссылками GitHub (ЛИНЗА с альбомной записью внизу)

ЛИНЗА с альбомной записью: холст в клетку через «рыбий глаз» идёт на весь кадр, запись спикера стоит внизу полосой 35% высоты, камера едет по 12 станциям, а предмет-эстафета (адресная строка с одним меняющимся словом) связывает три трюка.

- Карта монтажа и решения: `DIRECTION.md`.
- Код: `src/reels/rm/ghtricks/` (`Reel.tsx`, `words.ts`), общий каркас `src/reels/rm/lensLow.tsx`, механика стиля `src/kit/lens.tsx`, полоса записи `src/kit/strip.tsx`. Композиция для студии Remotion: `Lens-GhTricks`.
- Кадры готового ролика: `frames.jpg`.

Что не входит в курс. Запись спикера (альбомная 1912×1080, голос берётся из неё же) в репозитории не лежит. Композиция рендерится с заглушкой вместо лица (студийный фон и микрофон) и без голоса. Чтобы собрать свой ролик, положи запись в `public/work/<slug>/` и впиши путь в константу `REC` в начале `src/reels/rm/ghtricks/Reel.tsx`; если у твоей записи другие размеры, поправь `srcW` и `srcH` рядом. Снимки сервисов (GitHub, GitDiagram, Gitingest, DeepWiki) лежат в `public/ghtricks`.
