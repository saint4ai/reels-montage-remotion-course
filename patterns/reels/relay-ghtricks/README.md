# Трюки со ссылками GitHub (ЭСТАФЕТА 35%)

ЭСТАФЕТА 35% (CHROMA RELAY плюс полоса записи 35% внизу): цвет мира идёт за брендом сервиса, один предмет (адресная строка, в которой меняется одно слово) проходит через весь ролик, запись спикера стоит полосой внизу.

- Карта монтажа и решения: `DIRECTION.md`.
- Код: `src/reels/ghtricks/` (`Reel.tsx`, `words.ts`), блоки стиля `src/kit/relay.tsx`, `src/kit/strip.tsx`, `src/kit/reactbits.tsx`, `src/kit/studio.tsx`. Композиция для студии Remotion: `Relay-GhTricks`.
- Кадры готового ролика: `frames.jpg`.

Что не входит в курс. Запись спикера (альбомная 1080×610) и голос в репозитории не лежат. Композиция рендерится с заглушкой вместо лица (студийный фон и микрофон), без голоса, а полосы голоса в плеере пляшут условно. Чтобы собрать свой ролик, положи запись и голос в `public/work/<slug>/` и впиши пути в константы `REC` и `VOICE` в начале `src/reels/ghtricks/Reel.tsx`; размеры записи задают `REC_W` и `REC_H` рядом. Снимки сервисов лежат в `public/ghtricks`.
