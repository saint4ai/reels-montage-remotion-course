# Ролик 26 «Search Console находит трендовые темы»: карта монтажа

Решение Александра 25.09.2026: монтирует «Монтаж Рилс» сам (работу GLM не смотреть), стиль смесь ORBIT и Сцен, кадры
из рефа можно вырезать, профиль Instagram в них замазать. Голос `Гугл серч консоль.WAV` (34,9 с, без лица), конец на
«промпт для Claude» ≈ 34,3 с. Кадр 2K 1440×2560, 60 fps, графика на весь экран, субтитры 53,3 px светлые, центр y 1467.

## Мир

ORBIT: графитовый космос, оранжевый край планеты, мятные туманности; настоящие логотипы и предметы на трёх слоях
глубины, плывут с разной скоростью всё время. Сцены: хук и финал со сменой фона на каждом смысловом блоке.
Схема (подключил → запросы → растут → 24 часа → отчёт → Claude → темы) идёт на одном орбитальном холсте: блоки лежат на
эллипсе вокруг Search Console, камера летит по орбите от блока к блоку (0,7 с, power3.inOut, отдаление 0,74 посередине,
прошлый блок виден), пунктир орбиты дорисовывается на ходу. Интерфейс Search Console спроектирован заново в тёмном стекле
ORBIT, настоящие куски рефа с замазанным профилем стоят рядом как подтверждение.

темы; фильтр 24 часа; экспорт в таблицу; данные в течение 48 часов (надпись интерфейса); для всех стран с 29.07.2026.
