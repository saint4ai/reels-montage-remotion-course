# Ролик 23 «Opus — начальник» — что сделано и что сработало

Сдан 24.09.2026 с MacBook: `OneDrive/Reels/Opus тимлид/Opus тимлид — финал 4K.mp4` — 2160×3840, 60 fps, 63,3 с, 80 Мбит/с,
−14,2 LUFS / −1,3 dBTP. Запись `IMG_7881.MOV` (в Git не идёт; рабочие копии `labs/remotion-route/public/r23/speaker*.mp4`).

**Стиль:** 4 СЦЕНЫ в режиме канваса — белый кинетический холст в верхней половине (референс Александра 24.09: белый лист,
слова по одному, рывки камеры с размытием в движении, огромный циферблат, ряд людей с выделенным центром, кольца-счётчики,
соты со связями, облако пилюль, печать с кареткой). Он снизу во всю ширину — раскладка A «Шов» (выбрана по кадру К5).
Палитра бренда: оранжевый, мятный, чёрный, белый; Inter Tight / Manrope / Caveat / JBM; настоящая искра Claude.

**Код:** `labs/remotion-route/src/reels/opus/` — `Reel23.tsx` (композиция `Reel23`, точка входа `src/index-opus.ts`),
`kinetic.tsx` (камера `camAt` + размытие в движении `blurOf`, `KWords`, `Ring`, `EllipseMark`, `PaperBg`), `Hook.tsx` (0–10 с),
`Body.tsx` (10–63 с), `Terminal.tsx` (живой терминал Claude Code), `words23.ts` (расшифровка с правкой терминов), `hybrid.tsx`
(раскладки A/B/C гибрида). Пробы: `Opus-Test10`, `Opus-Price`.

**Что Александр принял:** стиль целиком («мне очень нравится стиль монтажа»); живой терминал Claude Code, где идёт работа;
стеклянная капсула Opus, которая раскалывается о терминал.

**Что он поймал и что стало правилом** (память `montage-overlap-checks`): пилюли стопкой налезали друг на друга и на подпись;
пилюли над сотой — на подзаголовок и соту; плейсхолдер поля в 2 строки; кривой овал-обводка вместо маркера по слову.
Сетка кадров через 2 с их пропустила — проверять кадры каждые 0,5 с и конечное состояние каждой сцены с разметкой зон Instagram.

**Цифры в кадре:** только прайс Anthropic ($20 / $10 / $5 за 1M токенов ответа, «×4»; снимок `public/r23/shots/pricing.png`)
и документация Claude Code (`opusplan`: plan → Opus 5.5, код → Sonnet 5). «В 5 раз медленнее» — только в субтитрах (его речь).
