# Каталог паттернов монтажа

Всё, чем собирались ролики @saint4ai: стили целиком, паттерны отдельных роликов, паттерны движения, переходы, приёмы и разборы
референсов. Агент берёт отсюда **метод и блоки**, а карту монтажа каждый раз придумывает заново под текст
(«своя карта монтажа», навык `.claude/skills/onai-montage/reference/04-build.md`).

Ссылки на `knowledge/`, `skills/onai-*`, `videos/` и `reference/` внутри документов стилей и роликов ведут в приватный
репозиторий автора и в курс не входят: всё нужное для работы собрано в навыке.

Картинки для выбора владельцем, прямо в чат: `public/style-previews/formats.jpg` (форматы из рабочих роликов),
`public/style-previews/styles.jpg` (стили каталога), `public/style-previews/sheet.jpg` (стиль 15 ЛИСТ) и `public/style-previews/business.jpg` (семь форматов для бизнеса, пересборка: `node scripts/business-board.mjs`). Те же форматы и стили словами: `docs/guides/patterns.md`. **Правила работы и порядок шагов в навыке
`.claude/skills/onai-montage/`, он главнее этого каталога.**

## С чего начать новичку

Три стиля, в которых собраны самые просматриваемые ролики автора курса. Если нет сильных причин брать другой, выбирай из них:

1. **ЭСТАФЕТА 35%.** Цвет идёт за сервисом, один предмет (например, адресная строка) проходит через весь ролик и меняется по смыслу, спикер полосой внизу. Хорошо для «трюков», списков и разборов инструментов.
2. **ЭКСПЕРТ.** Лицо крупно на нижней половине, сверху платиновая доска с заголовком, карточками и настоящими снимками сервисов. Проще всего собрать: данные плюс стиль одной строкой.
3. **ЛИНЗА.** Белый холст в клетку через «рыбий глаз», стеклянные капсулы на каждое слово, камера плавно едет между станциями. Хорошо для рассказа о продукте с цифрами и состояниями.

Принцип, который важнее выбора стиля: **первые 3 секунды огромный текст.** Кадр 0 уже полный: одна фраза из 4…6 слов крупным
шрифтом, контраст, без мелких подписей и иконок. По статистике автора, когда в первые 3 секунды листают меньше 40% зрителей,
охват в разы выше; мелкий текст в хуке давал пропуск больше половины. Дизайн и детали начинаются после третьей секунды.

У каждого ролика в `patterns/reels/<ролик>/` лежит `frames.jpg`: кадры из готового MP4.

автора: вместо лица заглушка, путь записи ученика вписывается в константу `REC` в начале файла ролика.

Стили 5–13 собраны на одном движке `src/styles/engine.tsx`: данные ролика — те же блоки, что у КАНВАСА (`hook`, `list`,
`stat`, `logos`, `flow`, `cta`), сцена на каждый блок, переход между сценами — из `kit/presentations`, спикер и субтитры поверх.
Поменять стиль ролика = поменять одну строку в точке входа (`reelOf(ORBIT)` вместо `reelOf(PRISM)`). Раскладки спикера:
`card` (карточка по формату), `square`, `roam` (квадрат переезжает), `circle` (пульс по речи), `half` (половина кадра: APPLE, ЭКСПЕРТ), `podcast`. У блока может быть `shot` — снимок сервиса (его показывает ЭКСПЕРТ).

## Эффекты текста — `src/kit/remocn/`

Маркер-выделение, RGB-глитч, подъём по буквам, появление из-под маски, трекинг, блик по слову, матричная расшифровка, барабан

три тарифа, глава, пометки, графики, схема-поток, плавный наезд) — `src/reels/early/`.
