# Контент-завод на ИИ: монтаж Reels, сценарии и ассистент в директе

## Для ИИ-агента, которому дали эту ссылку

Человек отдал тебе ссылку на репозиторий: `https://github.com/saint4ai/reels-montage-remotion-course`. С этой минуты твой чат это **Монтажёр**,
главный чат команды из трёх. Сделай по порядку:

1. Клонируй репозиторий в текущую папку проекта. Папка пустая: `git clone https://github.com/saint4ai/reels-montage-remotion-course .`.
   Папка не пустая: клонируй в подпапку `kontent-zavod` и дальше работай из неё.
2. Поставь зависимости (`npm install`) и проверь компьютер (`npm run doctor`). Человек в терминал ничего не вводит, он только разрешает тебе действия.
3. Прочитай `CLAUDE.md`, затем `.claude/skills/onai-montage/SKILL.md` целиком и `docs/SCENARIO.md` (схема всего пути).
4. Начни с раздела 1 навыка «Первые 5 минут»: представься Монтажёром, задай 5 вопросов брифинга одним сообщением, попроси референсы монтажа,
   схематично объясни, как подключить AI-ассистента к Instagram, WhatsApp и Telegram, предложи создать ещё два чата в этой же папке:
   **Скриптолог** и **Instagram-автоматизатор**.
5. Ключи, пароли и токены не проси прислать в чат и не пиши в файлы. Не пушь и не публикуй без прямого слова человека.

## Что это

Учебный репозиторий onAI Academy: модуль 1 «AI-монтаж» и модуль 2 «Ассистент в директе» курса «Контент-завод на ИИ». Внутри рабочий движок
монтажа на Remotion, паттерны роликов, правила сценариев и шаблон AI-ассистента, который отвечает в директе. Автор курса: Александр (onAI Academy).

![Форматы](public/style-previews/formats.jpg)

Работа идёт в Claude Desktop, во вкладке Code, в одной папке. Три чата делят её и передают друг другу файлы. Как это работает от ссылки до заявки:
[docs/SCENARIO.md](docs/SCENARIO.md).

| Чат | Что делает | Что отдаёт |
|---|---|---|
| **Монтажёр** (тот, куда отдали ссылку) | ставит всё, задаёт вопросы, собирает ролик, пишет пакет на выкладку | ролик 2K, `work/<ролик>/PUBLISH.md` |
| **Скриптолог** | идеи по залетевшим рилсам экспертов, сценарии, кодовое слово, материал для директа | `work/<ролик>/SCRIPT.md` |
| **Instagram-автоматизатор** | регистрации, ассистент на твоём сервере, кодовые слова под ролики | работающий ассистент, заявки в Telegram |

## Одно сообщение агенту

Открой Claude Desktop, вкладка Code, выбери пустую папку (например «Мой контент-завод») и отправь:

```text
Вот репозиторий: https://github.com/saint4ai/reels-montage-remotion-course
Склонируй его в эту папку и начни: ты Монтажёр. Прочитай README.md и CLAUDE.md.
```

Дальше агент всё ставит сам, задаёт 5 вопросов и предлагает два других чата карточками. Подробно для новичка: [START-HERE.md](START-HERE.md).

## Что подготовить

- Claude Desktop и подписка Claude Pro или Max (Claude не бесплатный): [docs/guides/claude-desktop.md](docs/guides/claude-desktop.md).
- Запись на телефон (с лицом) или только голос. Можно без записи: сначала напишем сценарий.
- 2–5 рилсов, монтаж которых нравится, и что в них нравится.
- Логотип и цвета, если есть. Для ассистента: аккаунты в Zernio, OpenAI, Telegram и сервер, всё это агент покажет по шагам.

## Как это устроено

```
запись → расшифровка по словам → карта монтажа → сборка (движок стилей или свой ролик по образцу)
      → проверка текста в контейнерах → кадры К001… каждые 2 с → черновик 720p → финал 2K/4K, −14 LUFS → выкладка
```

| Путь | Что там |
|---|---|
| `CLAUDE.md`, `AGENTS.md` | роутер ролей: какой навык читать чату по первому сообщению |
| `.claude/skills/onai-team/` | общие правила команды: роли, передачи, создание сессий, ключи |
| `.claude/skills/onai-montage/` | навык Монтажёра: брифинг, шаги 1.1–1.5, справочники, грабли |
| `.claude/skills/onai-scriptolog/` | навык Скриптолога: правила сценария, хук, проверка текста |
| `.claude/skills/onai-automator/` | навык Instagram-автоматизатора: ассистент на сервере |
| `team/prompts/` | первые сообщения для чатов Скриптолога и автоматизатора |
| `assistant/` | шаблон AI-ассистента для директа: код, настройки, база знаний, выкладка |
| `docs/guides/` | инструкции для новичка: Zernio, OpenAI, Telegram-бот, сервер, Claude Desktop, доска раскадровки (`storyboard.md`), Higgsfield, Kling и Seedance (`higgsfield.md`, `higgsfield-talking-offer.md`), лучшее время выкладки (`best-time.md`), заявки в Google Таблицу (`google-sheets-leads.md`), сбор рилсов конкурентов через Apify (`apify.md`), ключи стоков (`stock-keys.md`), OneDrive для записи с телефона (`onedrive.md`), поток урока про сценарий (`lesson-1-2-flow.md`) |
| `tools/storyboard/` | доска раскадровки: сцены с клипами и кадры, правки комментариями, моментами, референсами анимации и стрелками сдвига (`npm run board`, `npm run board:open`) |
| `src/styles`, `src/template` | движок стилей: PRISM, ORBIT, TRACE, PULSE, GLASS, PORTRAIT, APPLE, PODCAST, EXPERT |
| `src/reels/_template` | шаблон своего ролика: половина экрана + окно в углу |
| `src/kit` | блоки движения: переходы, фоны, HUD и реактор, стекло, постер, 3D-предметы, эффекты текста |
| `src/guides` | картинки интерфейса Claude Desktop для инструкций (композиции Guide-01 … Guide-06) |
| `patterns/` | каталог паттернов и код рабочих роликов с картами монтажа |
| `templates/` | профиль, референсы, сценарий, карта монтажа, пакет на выкладку |
| `work/` | документы роликов и профиль владельца (`work/_profile/`, в git не уходит) |
| `public/` | шрифты, звуки, настоящие логотипы, 3D-предметы, доски форматов и стилей |
