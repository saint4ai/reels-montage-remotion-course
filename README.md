# Автомонтаж Reels с AI и Remotion

Учебный репозиторий onAI Academy. Он ведёт человека без монтажного опыта от исходника и референсов до проверенного вертикального ролика 1080x1920.

## Самый короткий старт

Отправьте агенту ссылку на этот репозиторий и сообщение:

> Клонируй репозиторий, прочитай AGENTS.md и проведи меня по процессу. Сначала задай вопросы и покажи четыре стиля. Не собирай финальный MP4 до моего одобрения кадров.

Агент должен начать с интервью, а не с кода. Полная инструкция для человека находится в [START-HERE.md](START-HERE.md).

## Команды

```bash
npm install
npm run doctor
npm run studio
npm run frames
npm run render
```

- `npm run studio` открывает интерактивный предпросмотр Remotion.
- `npm run frames` создаёт кадры каждые 2 секунды для согласования.
- `npm run render` разрешён только после одобрения кадров.

## Структура

```text
AGENTS.md                 правила для Codex и других агентов
CLAUDE.md                 тот же вход для Claude Code
START-HERE.md             инструкция для ученика
docs/                     бриф, референсы, сториборд, QA и промпты
project/project.json      текущая тема, стиль, текст и тайминги
public/input/             видео, аудио, логотипы и скриншоты проекта
public/style-previews/    четыре визуальных направления
src/                      Remotion-композиция
reviews/                  кадры для согласования
out/                      финальный MP4
```

## PDF-гайд

Готовая презентация лежит в `output/pdf/`. Для пересборки установите зависимости и запустите генератор:

```bash
python3 -m pip install -r requirements.txt
python3 scripts/build_pdf_guide.py
```

Логотип берётся из `public/onai-platform-logo.svg` - это векторный onAI-вордмарк из интерфейса платформы.

## Важные ограничения

- В этом репозитории используется только Remotion.
- Референс задаёт механику, ритм и композицию, но не разрешает копировать чужой бренд кадр в кадр.
- До одобрения кадров каждые 2 секунды финальный MP4 не создаётся.
- Секреты, токены и приватные файлы не коммитятся.
