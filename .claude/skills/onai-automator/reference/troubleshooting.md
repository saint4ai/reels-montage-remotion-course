# Если что-то не работает

Начни всегда с `cd assistant && python -m app.check`: он покажет FAIL по каждому пункту, ключи не печатает.
Логи на сервере (в них нет текстов людей и ключей): `ssh root@<IP> "cd /opt/assistant && docker compose logs --tail 100 app"`.

| Что видно | Причина | Что делать |
|---|---|---|
| `app.check`: `FAIL Zernio: ключ не принят (401)` | ключ неверный или удалён | попроси ученика создать новый ключ (read-write, группы `messages` и `webhooks`), по правилу ключей положи в `.env`, `deploy/update.sh --with-env` |
| `FAIL Zernio: доступ закрыт (403)` | у ключа нет нужных групп или старый тариф без входящих | `docs/guides/zernio.md`, раздел про цены и про ошибку 403; создать ключ заново |
| `FAIL Zernio: вебхук не зарегистрирован` | не запускали `register_webhook.py` или сменился домен | `python deploy/register_webhook.py --env .env --domain <домен> --test` |
| `FAIL Сервер: /health` | сервис не запущен, закрыты порты 80 и 443 или не сошёлся домен | `ssh ... docker compose ps`, логи `caddy`; в панели провайдера открыть порты; для sslip.io при лимитах сертификата подождать или взять свой домен |
| `FAIL Модель: запрос: ключ не принят` | неверный `OPENAI_API_KEY` или `OPENAI_BASE_URL` | заменить ключ; для OpenRouter адрес `https://openrouter.ai/api/v1` и модель вида `openai/<модель>` |
| `FAIL Модель: запрос: похоже, закончился баланс` | пустой баланс или достигнут лимит расходов | пополнить баланс или поднять лимит (`docs/guides/openai.md`); владельцу об этом пишет и сам ассистент в Telegram |
| `FAIL Модель: вызов функций (заявки)` | модель не умеет tools | взять другую модель (`docs/guides/openai.md`); без tools заявки не сохранятся |
| `FAIL Модель: голосовые` | адрес не умеет расшифровку (у OpenRouter нет `/audio/transcriptions`) | `[voice] enabled = false` в `config/assistant.toml`, `deploy/update.sh` |
| `FAIL Модель: картинки` | модель не принимает картинки | `[vision] enabled = false` или другая модель |
| `FAIL Telegram: чат заявок` | бот не видит чат | ученик нажал Start у бота; в группе добавить бота и написать `/start@имя_бота`; `python deploy/find_chat_id.py` |
| В `app.check` FAIL про заглушки | остались `[[ЗАПОЛНИ: …]]` | заполнить файлы, указанные в выводе |
| Комментарий с кодовым словом без ответа | вебхук не доходит, слово не распознано или комментарий старше 7 дней | логи `app`; в панели Zernio журнал доставок вебхука; проверить `match` и `variants` слова |
| Материал не пришёл в директ, ошибка про уже использованный ответ | на комментарий разрешён один личный ответ; старше 7 дней нельзя | попросить человека написать слово в директ или новым комментарием |
| Публичный ответ есть, материала в директе не видно | код отвечает публично только после того, как материал ушёл, значит он у человека, но Instagram положил его в «Запросы сообщений» | попросить человека открыть директ, раздел «Запросы»; логи `app` |
| Ассистент молчит на вопрос | пауза после заявки или ответа владельца, диалог выключен кнопкой, выключен `[assistant] enabled`, суточный лимит | кнопка «Включить ассистента» в Telegram; `config/assistant.toml`; лимиты в `[limits]` |
| Ассистент отвечает заготовкой «Уточню этот момент…» | ответ дважды не прошёл проверки (сумма или ссылка не из базы, длина, обещание) | в логах причина; дополнить базу знаний или правило в промпте, проверить `python -m app.try` |
| Ответы звучат не как ученик | пустой раздел «Как общаться» в промпте | примеры фраз ученика добавить в `prompts/assistant.md` |
| Сообщение в WhatsApp или Instagram через сутки не ушло | окно Meta 24 часа закрыто | так и должно быть; напомнить человеку нельзя, пока он не напишет снова |
| Instagram прислал предупреждение аккаунту | подозрение на спам: одинаковые ответы, ссылки незнакомым, условие подписки | убрать условие подписки из материала, не рассылать вручную, сказать ученику не отвечать массово; публичные ответы уже вразнобой |
| Эхо наших сообщений ставит диалог на паузу | эхо пришло без `sentVia`, и id не совпал | в логах `handle_echo`; текст сообщения совпадает с последними ответами, поэтому обычно не срабатывает; если повторяется, описать в `assistant/README.md` и показать код |

## Перезапуск и откат

- Перезапустить: `ssh root@<IP> "cd /opt/assistant && docker compose restart app"`.
- Выложить исправления: `bash deploy/update.sh root@<IP> --env .env`.
- Выключить ответы в директе (материал по слову продолжит уходить): `[assistant] enabled = false` в `config/assistant.toml` и `deploy/update.sh`.
- Остановить всё: `ssh root@<IP> "cd /opt/assistant && docker compose down"` (база в томе остаётся).
- Копия базы: `bash deploy/backup.sh root@<IP>`.
