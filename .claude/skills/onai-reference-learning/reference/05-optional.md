Проверено по GitHub и README 10.10.2026; установку на этом курсе мы сами не прогоняли, поэтому если команда не сработала, смотри README проекта.

## Лицо точнее: mediapipe

`python -m pip install mediapipe`, плюс файл модели `blaze_face_short_range.tflite` (около 230 КБ) из каталога моделей MediaPipe: положи в `work/_refs/.models/`
(скачивание файла только с разрешения владельца) или укажи путь в переменной `REF_FACE_MODEL`. Тогда `ref-analyze.py` берёт его вместо Haar, в сводке будет `Лицо (mediapipe)`.
Без модели скрипт молча остаётся на Haar. Нужен, когда Haar не находит лицо в маленьком окне, под наклоном или в стилизованной рамке (Apache-2.0, google-ai-edge/mediapipe).
Этот путь мы не прогоняли на реальной модели: если не сработал, остаётся Haar, ничего не ломается.

## Темп музыки: librosa

`python -m pip install librosa` (пакет тяжёлый, ставится дольше), затем `python scripts/ref-analyze.py work/_refs/<имя>/ref.mp4 --beats`.
В профиле появится `audio.beats`: темп в ударах в минуту и первые биты. Нужен для роликов, где склейки бьют в музыку.

## Официальные навыки Remotion

Репозиторий `remotion-dev/skills`: 4 990 звёзд, последняя активность 7 октября 2026, ведёт команда Remotion. Ставится так:
```text
npx skills add remotion-dev/skills
```
Даёт агенту навыки по правилам работы с Remotion: `remotion-best-practices` (охватывает остальные), `remotion-markup` (вёрстка, анимации, шрифты, звук, тайминг),
`remotion-create`, `remotion-studio`, `remotion-render`, `remotion-maps`. Пригодятся, когда собираешь вариант стиля с незнакомым приёмом. Навыки курса главнее:
при расхождении прав `.claude/skills/onai-montage/SKILL.md`. Лицензия в репозитории не указана, ставит агент, когда владелец сказал «да».

## MCP «глаза и уши»: watch-skill

Репозиторий `oxbshw/watch-skill` (MIT, 472 звезды, обновлялся 14 сентября 2026): превращает видео в кадры с временными метками, текст с экрана (OCR) и расшифровку
и умеет отвечать «что изменилось на 3:12». Установка по README: `pip install 'watch-skill[standard,ocr]'`, сервер MCP запускается командой `watch-skill serve`.
Подключается к Claude Code как MCP-сервер. Он лишний, если хватает `ref-analyze.py` и твоих глаз; полезен, когда нужен текст с экрана референса (например, как набран заголовок)
или сквозной разбор длинного ролика.

## Смысловой разбор через Gemini

Модель смотрит ролик целиком и пишет разбор: приёмы, структуру, настроение. Платно, нужен ключ владельца. Правило ключей из `.claude/skills/onai-team/SKILL.md`:
владелец сохраняет ключ файлом в «Загрузках» и называет тебе имя файла, значение нигде не показывается. Перед запуском посчитай цену по актуальному прайсу Google (оценки в
открытых обзорах расходятся от десятков центов до нескольких долларов за ролик), скажи владельцу сумму и жди «да». Без разрешения видео никуда не отправляется. По умолчанию его не используем:
замеры, кадры и твои глаза дают то же без денег.
