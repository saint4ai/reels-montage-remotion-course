# Дообучение на референсах

Автоматического «перенеси стиль с этого ролика» для моушн-дизайна нет. Работает связка: **измерить референс, записать паспорт стиля,
собрать по паспорту, сверить с референсом**. Замеры бесплатные и локальные, видеокарта не нужна. Глаза тут твои: числа показывают
ритм и палитру, а хук, типографику и характер движения ты берёшь из кадров.

Учимся стилю, а не копируем ролик. Чужие кадры, звук, лица, логотипы автора и дословные тексты в наш ролик не попадают.

## 0. Нельзя

1. Брать в свой ролик кадры, записи, голос, музыку, логотипы и тексты референса. Берём приёмы: ритм, механику, роль цвета, плотность.
2. Класть референсы куда-то, кроме `work/_refs/` (папка в `.gitignore`), коммитить их, публиковать, загружать в облако или отправлять
   в чужие сервисы без слова владельца.
3. Заполнять раздел паспорта «по общим соображениям». Не видишь по кадрам: пиши «не видно» и почему.
4. Брать пароли и cookies из браузера владельца, чтобы скачать ролик. Не скачался: попроси файл (раздел 2, шаг 1).
5. Запускать замер одновременно с рендером, `npm run frames` или студией. Один тяжёлый процесс за раз (правило курса, `onai-montage`, раздел 5).
6. Подключать платные сервисы без слова владельца. Ключ только по правилу ключей из `.claude/skills/onai-team/SKILL.md`.
7. Тексты для владельца: короткие предложения, на «ты», без длинных тире и штампов (правило команды, `.claude/skills/onai-team/SKILL.md`).

## 1. Что нужно на компьютере

- Python 3.10 или новее (`python --version`; на macOS `python3`), ffmpeg (его проверяет `npm run doctor`).
- Пакеты замера. Скрипты сами ничего не ставят: если пакетов нет, печатают команду. Ставь её сам и разреши, что просит система:
  ```text
  python -m pip install -r scripts/ref-requirements.txt
  ```
  Лучше в отдельном окружении: `python -m venv work/_refs/.venv`, дальше запускай скрипты тем Python, что внутри (`work/_refs/.venv/Scripts/python`,
  на macOS `work/_refs/.venv/bin/python`). Пакет `opencv-python` закреплён ниже 5-й версии: в OpenCV 5 нет каскадов Haar, по которым ищется лицо.
- Необязательно: `mediapipe` (лицо точнее), `librosa` (темп музыки, флаг `--beats`). См. `reference/05-optional.md`.

## 2. Шаги

### Шаг 1. Принять референс
Создай `work/_refs/<имя>/`, имя короткое латиницей (`ghtricks`, `anna-reels`).
- Владелец положил файл: перенеси или скопируй в `work/_refs/<имя>/ref.mp4` (любое расширение видео).
- Владелец дал ссылку: попробуй `yt-dlp -o "work/_refs/<имя>/ref.%(ext)s" "<ссылка>"` (если `yt-dlp` стоит). Instagram часто не отдаёт видео без входа.
  Не вышло с первого раза: не лезь в браузер владельца, скажи просто: «Эту ссылку я не могу открыть. Скачай ролик на телефон или компьютер и положи
  файл в папку `work/_refs/<имя>/`, я скажу, где она лежит».
- Расшифровка нужна для темпа речи и текста хука (необязательно): `npm run transcribe -- work/_refs/<имя>/ref.mp4 work/_refs/<имя>/words.json --lang ru`
  (язык ролика: `--lang en` для английского). Первый запуск скачивает модель около 1,5 ГБ. Это тяжёлый процесс, не запускай его параллельно с замером.

### Шаг 2. Замер
```text
python scripts/ref-analyze.py work/_refs/<имя>/ref.mp4
```
Рядом с роликом появятся `profile.json` (все числа), `sheet.jpg` (кадр раз в секунду с подписью времени, оранжевая черта: в эту секунду сменилась сцена),
`hook.jpg` (кадры 0, 0,5 … 3 с крупнее) и папка `shots/` (средний кадр каждого плана). В консоли короткая сводка. Что значит каждое поле:
`reference/01-measurements.md`. Главное число темпа это `rhythm` (смены сцены: склейки плюс хлысты, смаз и переезды камеры). Число «планов» детектор считает только по резким
склейкам, у роликов с камерой по холсту оно занижено. Склеек подозрительно мало или много: перезапусти с `--threshold 2` (чувствительнее) или `--threshold 5` (грубее) и сверь с листом.

### Шаг 3. Смотреть глазами
Открой картинки инструментом чтения изображений, по порядку:
1. `hook.jpg`: что в кадре 0, сколько слов, насколько крупно, что движется до 3-й секунды.
2. `sheet.jpg`: смена фонов, цветовые зоны, где появляется человек, как часто меняется картинка.
3. 6…10 кадров из `shots/`: первый, самый короткий и самый длинный план, последний. Склеек мало: открой кадры в секундах `rhythm.times` и `motion.peaks_s` на листе
   (оранжевые черты) и определи, что там меняется: склейка, хлыст, переезд камеры.
Не пересказывай числа вместо кадров и не угадывай шрифт по памяти: смотри на буквы.

### Шаг 4. Паспорт стиля
Создай `work/_profile/styles/<имя>/`, скопируй туда `templates/STYLE.md` и заполни по `reference/02-style-passport.md`: хук, раскладка, типографика,
палитра (из `profile.json`), словарь движения, плотность, субтитры, звук и музыка, что берём, что НЕ копируем, ближайший стиль каталога и отличия.
Скопируй рядом `profile.json` и `sheet.jpg`. Добавь строку в `work/_profile/refs.md`: в колонке «Что берём» допиши
`паспорт: work/_profile/styles/<имя>/STYLE.md`, в колонке «Что не копируем» чужие кадры, звук и тексты.
**Ворота:** покажи владельцу паспорт короткой сводкой в 8…10 строк (хук, раскладка, цвета, темп, ближайший стиль, что не копируем) и жди «ок» или правок.

### Шаг 5. Вариант стиля в коде
Не с нуля: возьми ближайший стиль каталога и перенеси отличия паспорта параметрами (палитра, шрифты, длительности, переходы, раскладка спикера).
Порядок и таблица «поле паспорта → что менять в коде»: `reference/03-code-variant.md`. Результат: **тестовая сцена 10…15 секунд** на демо-данных или на
первых блоках настоящего ролика. Кадры: `npm run qa -- <композиция>`, затем `npm run frames -- <композиция>` (по одному, не вместе). Правила качества
из раздела 5 навыка `onai-montage` действуют и здесь: первые 3 секунды огромный текст, текст в контейнерах, безопасные зоны Instagram.

### Шаг 6. Сверка
Собери черновик тестовой сцены (`npm run draft -- <композиция>`, файл `out/<композиция>-draft.mp4`) или возьми папку кадров `reviews/<композиция>-vNNN` и сравни:
```text
python scripts/ref-compare.py work/_refs/<имя>/profile.json out/<композиция>-draft.mp4 --out work/_profile/styles/<имя>
```
Получишь таблицу «референс | наш | отличие | оценка», подсказки, что крутить, и лист `compare.jpg` «референс | наш» рядом (хук и ролик целиком). Покажи лист владельцу
и скажи по-человечески, что отличается. Крути параметры по `reference/04-compare-tuning.md`, не больше трёх кругов: числа показывают, насколько далеко
от референса, а красиво ли, решают глаза и владелец. Таблицу из `compare.md` вставь в раздел 13 паспорта.
**Ворота:** владелец увидел `compare.jpg` и сказал, подходит ли.

### Шаг 7. Запомнить и использовать
В `work/_profile/styles/<имя>/` лежат `profile.json`, `STYLE.md`, `sheet.jpg`, `compare.jpg`. В следующих роликах на шаге 1.3 предлагай этот стиль наравне
с каталогом: «У тебя есть свой стиль „<имя>“ (по референсу). Использовать?». Скриптологу в `work/_profile/refs.md` отдавай только приём хука одной строкой
(раздел 1 паспорта), без текста референса.

## 3. Где что лежит

| Путь | Что | В git |
|---|---|---|
| `work/_refs/<имя>/ref.mp4`, `words.json` | референс владельца | нет, папка в `.gitignore` |
| `work/_refs/<имя>/profile.json`, `sheet.jpg`, `hook.jpg`, `shots/` | результат замера | нет |
| `work/_profile/styles/<имя>/` | паспорт `STYLE.md`, `profile.json`, `sheet.jpg`, `compare.jpg`, `compare.md` | нет, папка профиля владельца |
| `src/styles/<имя>.tsx` или `src/reels/<имя>/` | вариант стиля в коде | да, это наш код без чужих кадров |
| `scripts/ref-analyze.py`, `ref-compare.py`, `ref-requirements.txt` | инструменты | да |
| `templates/STYLE.md` | шаблон паспорта | да |

## 4. Время и цена

Замер ролика в 45…60 секунд: около 50 секунд на ролик 47 секунд 1440×2560 при 60 к/с (замер 10.10.2026 на обычном компьютере без видеокарты в работе, один процесс; 4K и более длинные ролики идут дольше). Сверка с нашим mp4 около минуты (замер нашего ролика плюс лист «референс | наш»), по папке кадров около 15 секунд. Деньги не нужны: всё считается на компьютере, ключи не нужны.
Платное только в разделе «По желанию» и только по слову владельца.

## 5. Если не получилось

| Симптом | Лечение |
|---|---|
| «Не хватает пакетов» | команда из раздела 1; Python старше 3.10 обнови |
| Нет ffmpeg | `npm run doctor`, строка про ffmpeg |
| Планов 1 или 3 на ролике, где явно много сцен | плавные переходы, хлысты и камеру по холсту детектор не видит. Темп смотри по `rhythm` и оранжевым чертам листа; можно `--threshold 2`; впиши в паспорт, что считал по листу |
| Склеек очень много на спокойном ролике | мигание или 3D-вращение даёт ложные склейки: `--threshold 5` |
| Лицо «не найдено» при человеке в кадре | стилизованное лицо, поворот или маленькое окно: Haar такое не ловит; определи раскладку по кадрам сам и впиши в паспорт (необязательный `mediapipe`: `reference/05-optional.md`) |
| Лицо найдено там, где его нет | ложные срабатывания на графике: смотри `face.detect_rate` (меньше 0,3 не верь) и кадры |
| Путь с кириллицей, scenedetect не открывает | скрипт сам пробует копию с простым именем во временной папке; если не вышло, переименуй файл латиницей |
| Ссылка не скачивается | раздел 2, шаг 1: просишь файл |
| Референс на другом языке | `npm run transcribe … --lang en` (или код языка), либо пропусти темп речи |
| Замер долго идёт | идёт один проход по ролику и поиск склеек; не запускай параллельно рендер, на слабом компьютере 4K-референс идёт дольше |
