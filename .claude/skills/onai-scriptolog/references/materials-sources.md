# Где брать раздаточный материал для роликов любого бизнеса

Справочник чата «Скрипты для Reels» (прежнее название «Скриптолог»). Читай его, когда владелец одобрил тексты и ты предлагаешь собрать материалы (раздел 7 навыка). Курс держится на GitHub-репозиториях, но у владельца может быть что угодно: натяжные потолки, салон, кофейня, квартиры, обучение, товары. Поэтому источники ниже собраны под любой бизнес.

Проверено 11.10.2026: открывались страницы сервисов, документация API и публичные API (запросы без ключа). Три метки у каждого факта:

- **проверено**: прочитано на странице самого сервиса или получено ответом его API;
- **со слов поиска**: страница сервиса не открылась, цифра взята из выдержек в поиске или со сторонних сайтов, перед покупкой открой страницу сервиса;
- **не проверено**: проверить не удалось, так и написано.

Лицензии здесь пересказаны простыми словами и не заменяют юриста. Перед использованием файла смотри лицензию именно этого файла и записывай её в `SOURCES.md` (раздел 8).

## 1. Порядок поиска

1. **Свои материалы владельца.** Всегда первыми: фото работ, до и после, процесс, сайт, соцсети, записи экрана, 5–10 коротких планов на телефон. У узкого дела бесплатные стоки почти пустые (раздел 6, пример про натяжные потолки), а свои кадры к тому же правдивее.
2. **Материалы поставщиков и производителей** (каталоги, фото продукции, ролики): только с разрешения. Письмо или сообщение пишет владелец, ты готовишь короткий текст просьбы. Разрешение сохраняется в `SOURCES.md` строкой «разрешил <кто>, <дата>».
3. **Бесплатные стоки** (раздел 3): быстро, без оплаты, но кадр общий, а не про дело владельца.
4. **Платные стоки** (раздел 4): только по слову владельца, подписка платная.
5. **Генерация** (Higgsfield через MCP): для вставок, которых нет нигде. Платно, только после слова «да» и названной цены (`docs/guides/higgsfield.md`).

Что нужно в кадре, и где искать:

| Что нужно в кадре | Где искать |
|---|---|
| Процесс работы, руки, инструмент, результат | свои съёмки; потом Pexels, Mixkit, Coverr, Pixabay |
| Работа до и после | только свои фото владельца |
| Отзыв клиента | сам отзыв и согласие автора; имя скрываем (раздел 5) |
| Продукт, материал, каталог | сайт производителя с разрешением; свои фото |
| Общий фон, атмосфера, город, офис | Pexels, Mixkit, Coverr, Pixabay |
| Вертикальное видео 9:16 | категория «Vertical» на Mixkit; фильтр ориентации на Pexels |
| Фото для карточки или обложки | Unsplash, Pexels, Pixabay |
| Логотип сервиса | настоящий из `public/brand`, генерировать нельзя |
| Иконки | Simple Icons (CC0, логотипы брендов), Wikimedia Commons |
| Музыка и звуки | `public/sfx` курса; Mixkit; YouTube Audio Library (смотреть условия трека) |
| Интерфейс сервиса | запись экрана самого владельца или слепок интерфейса у «Монтаж Reels» |
| Вставка, которой нет в природе | генерация Higgsfield (после «да») |

## 2. Свои материалы владельца

- **Сайт и соцсети владельца.** Фото работ, до и после, видео процесса, сторис. Права у владельца, если снимал он или его сотрудник. Фото, где узнаются клиенты, берём с согласия клиента.
- **Отзывы.** Скриншот отзыва показываем с согласия автора, имя и фото автора закрываем. Отзыв, которого нет, придумывать нельзя.
- **Съёмка на телефон.** Если кадров нет, просишь владельца снять 5–10 планов по списку, который ты составил под фразы текста: «руки с инструментом», «замер», «результат целиком», «клиент смотрит» (с согласия). Вертикально, на постоянном свету, без дрожи.
- **Запись экрана.** Сервис, которым пользуется владелец, снимается его собственной записью экрана. Личные данные (почта, имена клиентов, цифры оплат) закрываем.
- **Отдельное правило про карты Google.** Страница правил Google для геоданных (проверено 11.10.2026) разрешает карты в ролике без запроса, если ролик учебный или развлекательный и рядом стоит отметка «Google». Рекламные и продающие ролики требуют согласования с Google, Street View нужен только по запросу. Про отзывы пользователей страница молчит. Вывод для курса: скриншот карты в продающий ролик не берём, отзыв с карты берём только как свой текст с согласием автора.

## 3. Бесплатные стоки

### Pexels (pexels.com): видео и фото

- **Лицензия** (проверено): бесплатно, можно в рекламе, указывать автора не обязательно (приветствуется), можно монтировать и менять. Нельзя продавать копии без изменений, показывать узнаваемых людей в плохом свете, подавать так, будто люди или бренды рекомендуют твой продукт, перепродавать на других стоках, делать из кадра товарный знак.
- **API** (проверено): `GET https://api.pexels.com/v1/videos/search`, параметры `query`, `orientation`, `size`, `page`, `per_page` (до 80); ключ в заголовке `Authorization`. Лимит по умолчанию 200 запросов в час и 20 000 в месяц. Условия API просят ссылку на Pexels там, где показываются результаты поиска.
- **Ключ:** бесплатный. **Важно:** на странице pexels.com/api/ на 11.10.2026 написано «New API key issuance is currently paused», выдача новых ключей приостановлена. Раздел документации об этом молчит. У кого ключ уже есть, тот работает. Новым ученикам: искать на сайте pexels.com без ключа (раздел 7).
- Ответ API (проверено по документации): `videos[].video_files[]` с полями `quality`, `file_type`, `width`, `height`, `link`; автор в `videos[].user.name` и `.url`; страница ролика в `videos[].url`.

### Pixabay (pixabay.com): видео, фото, иллюстрации

- **Лицензия** (проверено): бесплатно, без указания автора, можно менять. Нельзя продавать и раздавать файл отдельно в исходном виде, использовать с узнаваемыми товарными знаками и логотипами в коммерческих целях, подавать людей на кадре обманно или в незаконном контексте, делать из кадра товарный знак. На странице лицензии нет слов про Content ID и ИИ-контент, дату обновления страница не называет.
- **API** (проверено): `GET https://pixabay.com/api/videos/?key=<ключ>&q=<запрос>`, параметры `video_type`, `min_width`, `per_page` (3–200), `order`; **параметра `orientation` у видео нет**, вертикальность проверяй по `width` и `height`. В ответе `hits[].videos.large|medium|small|tiny` с `url`, `width`, `height`, `size`; у `large` адрес бывает пустым. Лимит 100 запросов за 60 секунд, ответы нужно кэшировать 24 часа, не больше 500 результатов на запрос, массовое скачивание запрещено, постоянные ссылки на чужие картинки запрещены (файл скачиваем к себе).
- **Ключ:** виден в аккаунте на странице документации после входа (документация: «you must log in to see your key»).
- Пример покрытия (проверено 11.10.2026): по запросу «renovation» на Pixabay 26 роликов.

### Mixkit (mixkit.co): видео, музыка, звуки

- **Лицензия** (по страницам Mixkit): «Stock Video Free License» разрешает коммерческое использование, в том числе рекламу и соцсети, без указания автора, без водяных знаков. «Stock Video Restricted License» только для личных некоммерческих проектов: такие ролики для бизнеса не берём. Перепродажа в исходном виде запрещена. **Полный текст лицензии открывается окном «View License» и в загрузке страницей не читается, поэтому смотри, какая лицензия стоит у ролика на его странице.**
- Есть категория «Vertical» (проверено), музыка и звуки идут по отдельным лицензиям («Stock Music Free License», «Sound Effects Free License»), их текст я не прочитал.
- **API и ключ:** подтверждения API не нашёл, берём руками на сайте.

### Coverr (coverr.co): видео

- **Лицензия** (проверено на странице лицензии): бесплатно, в том числе коммерчески, указывать автора не нужно. Нельзя перепродавать и раздавать как часть сервисов-конкурентов, нельзя использовать для обучения ИИ. Бренды и логотипы в кадре могут требовать разрешения владельца бренда. Разрешения на людей Coverr получает у себя, нам их не передаёт.
- **API** (проверено): бесплатный, если ты сам за него не берёшь деньги и не перепродаёшь видео; просят показывать кликабельный логотип Coverr. Как получить ключ, страница не сообщила (смотри api.coverr.co/docs). Лимиты не названы.

### Videvo

- **Проверено 11.10.2026:** адрес videvo.net/stock-video-footage/ перенаправляет (301) на freepik.com/videos. Страница freepik.com/videos не открылась (ответ 403), условия лицензии Videvo я не читал. Со слов поиска: Videvo куплен Freepik в 2022 году, часть роликов идёт под Creative Commons с обязательным указанием автора. Как отдельный источник не используем, см. Magnific ниже.

### Unsplash (unsplash.com): только фото

- **Лицензия** (проверено): бесплатно, в том числе коммерчески, указывать автора не обязательно (приветствуется). Нельзя продавать без существенных изменений и собирать из снимков сервис-конкурент. Про людей, товарные знаки и видео страница лицензии ничего не говорит.
- **API** (проверено): ключ создаётся на unsplash.com/oauth/applications, кнопка «New Application». Заголовок `Authorization: Client-ID <ключ>`. Новое приложение работает в «demo mode» с лимитом 50 запросов в час, после одобрения («Apply for Production») 1000 в час. Правила API: использовать адреса картинок из ответа (hotlink), каждое скачивание сопровождать запросом `GET /photos/:id/download`, указывать фотографа и Unsplash.

### Wikimedia Commons (commons.wikimedia.org)

- **Лицензия** (проверено): у каждого файла своя. Бывает общественное достояние (CC0), «CC BY» (нужно указать автора), «CC BY-SA» (указать автора и оставить ту же лицензию производной работе). Фонд не гарантирует точность лицензий. Отдельно могут действовать права на изображение человека, товарные знаки и частная жизнь.
- **API** (проверено реальным запросом без ключа 11.10.2026): `https://commons.wikimedia.org/w/api.php?action=query&generator=search&gsrnamespace=6&gsrsearch=filetype:video%20<запрос>&prop=imageinfo&iiprop=url|size|mime|extmetadata&format=json`. В `extmetadata` лежат `LicenseShortName` (например «CC BY 3.0», «CC0»), `Artist`, `AttributionRequired` («true» или «false»), `Credit`. Правило Wikimedia: в запросе должен быть осмысленный `User-Agent` с контактом, запросы идти по одному.
- **Нюансы:** видео чаще в форматах `.ogv` и `.webm`, нужна перекодировка ffmpeg в H.264; разрешения разные (в пробном запросе от 320×240 до 1920×1080). Нужен файл с `AttributionRequired: false` или с записью автора в `SOURCES.md`.

### Иконки и логотипы

- **Simple Icons** (simpleicons.org): логотипы брендов в SVG, лицензия набора CC0-1.0 (проверено через GitHub). Сами товарные знаки принадлежат брендам: для сервисов из курса берём настоящие логотипы из `public/brand`.

### Музыка

- **YouTube Audio Library** (проверено): бесплатно, у каждого трека своя лицензия: «Attribution not required» или Creative Commons с указанием автора в описании. Страница говорит только про ролики на YouTube, использование в Reels и TikTok она не описывает. Перед использованием вне YouTube читай лицензию трека.
- Звуки и музыка курса: `public/sfx` (решает «Монтаж Reels»).

## 5. Люди, бренды, отзывы

- **Чужие лица.** Люди из стоков допустимы по лицензии сервиса, но не подавай их так, будто они рекомендуют твой продукт (Pexels), и не показывай узнаваемых людей в плохом свете. Лица клиентов владельца и сотрудников только с их согласием.
- **Логотипы и товарные знаки в кадре.** Логотип сервиса из курса берём из `public/brand`, не генерируем. Чужие бренды на фоне стока в рекламе могут потребовать разрешения владельца бренда (Coverr, Pixabay прямо об этом предупреждают).
- **Водяные знаки.** Файл с водяным знаком отбрасываем.
- **Редакционные файлы** (editorial only, например в Magnific) в рекламе и продвижении запрещены.
- **Отзывы.** Только настоящие и с согласием автора. Имя, фото и ник закрываем.
- **Генерация лиц.** Чужое лицо и голос в Higgsfield только с согласия человека (условия Higgsfield, `docs/guides/higgsfield.md`).

## 6. Пример: натяжные потолки

Пример показывает, зачем узкому делу свои кадры. Проверено 11.10.2026 поиском на сайтах (без ключа, по первым результатам):

- Pexels, запрос «stretch ceiling»: около 11,4 тысячи результатов, но первые результаты не про натяжные потолки (окно, клиника, бассейн, интерьер). Ближе всего ролик «работники монтируют потолочные панели» в конце списка.
- Pixabay, запрос «stretch ceiling»: «107+» результатов, первые ролики про йогу, эскалатор и архитектуру. Один ролик с подписью «Working, Interior, Ceiling, Wiring, Work» стоит проверить глазами.
- Pexels, запрос «ceiling renovation»: результаты ближе к делу (шлифовка потолка, шпатлёвка стены, монтаж потолочных светильников).
- Pixabay, запрос «renovation»: 26 роликов.

Вывод для такого владельца:

1. Кадры монтажа, плёнки, света, до и после снимает сам владелец или бригада: список планов ты даёшь по фразам текста.
2. Фото и ролики производителей плёнки и профилей: с их разрешения (раздел 1).
3. Для общего фона и вставок «ремонт» подходят Pexels и Pixabay по запросам «ceiling installation», «ceiling renovation», «ceiling lights», «interior renovation».
4. Для вставки, которой нет (например, потолок с мягкой подсветкой в разрезе), предложить Higgsfield.

## 7. Как искать без ключа

Ключи у новичка бывают не сразу. Порядок:

1. **Без ключа**: сайты Mixkit, Coverr, Pixabay, Pexels открываются в браузере (встроенный браузер Claude или Claude in Chrome), выбираешь ролики и скачиваешь. Wikimedia Commons отвечает по API без ключа (раздел 3). Сайты бывают закрыты защитой от роботов (11.10.2026 запрос из скрипта к pexels.com получил страницу проверки браузера), тогда ищи в браузере, а не скриптом.
2. **С ключом**: если у владельца уже есть ключ Pixabay, Unsplash или Pexels, ищи через API по формулам выше.
3. **Нет ключа и нужен API**: короткая инструкция, как получить ключ, в `docs/guides/stock-keys.md`. Ключ владелец вставляет в чат, агент записывает его в `.env` и больше нигде не повторяет.

Имена переменных в `.env`: `PEXELS_API_KEY`, `PIXABAY_API_KEY`, `UNSPLASH_ACCESS_KEY`, `COVERR_API_KEY`, `APIFY_TOKEN`.

## 8. Как записывать источник

Для каждого файла в `SOURCES.md` рядом с файлами (папка ролика `Раздаточный материал/` в OneDrive, без OneDrive `work/<slug>/materials/`; шаблон `templates/SOURCES.md`):

- имя файла и фраза сценария, под которую он взят;
- сервис, адрес страницы файла, автор;
- лицензия простыми словами (например, «Pexels License, коммерчески можно, автор не обязателен») и нужно ли указывать автора;
