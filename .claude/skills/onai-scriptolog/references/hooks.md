# Хук: первая фраза до точки

Первая фраза: до 12 слов, до 2,5 секунды. На ней решается, досмотрят ли ролик.

## Цифры (45 рилсов автора курса, июнь–сентябрь 2026)

- Пролистывания до 40%: медиана 6 280 просмотров, максимум 106 656. Пролистывания 60% и выше: медиана 1 260.
- Минус 10 процентных пунктов пролистываний дают примерно ×1,9 просмотров. Плюс 10 репостов на 1 000 охвата тоже ×1,9.
- Оба хита: пролистывания 33–35%, репостов 21–24 на 1 000. Нужны оба числа сразу.

| Первая фраза | Пролист. | Просмотры | Почему |
|---|---:|---:|---|
| «Если у твоего Claude нет ни одного коннектора, ты платишь 20 долларов в месяц за очень умный калькулятор» | 34,6% | 106 656 | «ты» + деньги + абсурдный укол по инструменту зрителя |
| «Claude нашёл утечку в моей же воронке» | 33,5% | 63 843 | свой кейс, деньги, неожиданный результат |
| «Никогда не доверяйте ИИ юридические и финансовые решения» | 35,7% | 6 100 | запрет с высокой ставкой |
| «Как через Claude Code сделать ИИ-ассистента в директ» | 55,6% | 2 945 | инструкция без ставки |
| «Вы видели мои ролики с ИИ-монтажом» | 62,2% | 1 971 | заход для своих, незнакомец не видел |
| «Не каждый продукт стоит вайбкодить сразу до продакшена» | 64,7% | 738 | оговорка вместо тезиса, лекция |
| «Твой Claude не тупой, он просто голый» | 66,2% | 1 260 | метафору надо разгадывать, тема выгорела |
| «Забудь про вкладку usage в Claude или Codex» | 70,8% | 688 | нужен контекст, боль не названа |

Первый кадр работает вместе с фразой: в оригинале «4 коннектора» (две строки огромным шрифтом, лицо крупно) пропуск 33,9%, в перемонтаже того же голоса
с «дизайнерским» первым кадром 49,1%. Для монтажа: первые 3 секунды это одна фраза-ставка огромным шрифтом, 4–6 слов, максимум контраста.
Поэтому в `SCRIPT.md` всегда пиши, какие 4–6 слов станут экранным хуком и какой предмет или число покажем с нулевого кадра.

## Ворота: все пять «да»

1. **Незнакомец понимает без контекста.** Показ идёт в основном не подписчикам.
2. **Есть предмет или число**, которое монтаж покажет с нулевого кадра: 73 тысячи звёзд, кружка без пара, 250 документов.
3. **Есть заряд:** потеря денег или времени, угроза, запрет, абсурд, статус, чудо-результат, признание, личный страх.
4. **Это новость для этой аудитории.** Не «вокруг X много шума» через три недели после волны.
5. **Обещание выполняется в ролике** и ни одной строкой не отзывается.

## Триггеры, которые сработали

| Триггер | Пример |
|---|---|
| Укол по инструменту зрителя | «Твой Claude Code работает как стажёр, который сам себя проверяет.» |
| Личный страх автора | «Честно, мне уже страшно за монтажёров.» |
| Фишка для узнаваемой группы | «Классная бесплатная фишка для тех, кто ведёт свой блог.» |
| Роль, сори | «Тестировщики, сори: Google выложил инструмент, с которым Claude сам проходит приложение на телефоне.» |
| Кто создал + результат | «Один из создателей ChatGPT ушёл из OpenAI и выпустил нейросеть, которая до 200 раз быстрее.» |
| Гений / одиночка | «Китайский гений выложил бесплатный скилл, который превращает твоего Claude в дизайнера презентаций.» |
| Сгорел и сделал сам | «Один разработчик так сгорел от цен на SEO-сервисы, что написал свою бесплатную замену Semrush.» |
| Слухи подтвердились | «Слухи подтвердились: Anthropic больше месяца урезала усилие Claude Code и сама это признала.» |
| Мечта из поп-культуры | «Джарвис из „Железного человека“ теперь живёт у тебя в браузере.» |
| Разоблачение мифа | «Говорят, каждый твой запрос к ChatGPT выпивает пол-литра воды. Это миф.» |
| Число-шок | «Хакеру не нужно взламывать ИИ. Достаточно подсунуть ему 250 документов.» |
| Платное стало бесплатным | «Платный сервис с тысячами пользователей закрыли, а весь его код отдали бесплатно.» |
| Сцена потери | «Нарисовал логотип кофейни: чашка и тонкий пар. В аватарке пар исчез.» |
| Абсурд | «Попроси Claude добавить анимацию, и сайт запрыгает, как презентация из 2007 года.» |
| Ноль как результат | «Ты собрал приложение за вечер, а пользователей ноль.» |

Сильнее всего работают пары: число + укол, сцена + потеря, личная эмоция + конкретный предмет. Примеры про ИИ-инструменты показывают механику. Для своей ниши
подставь предмет владельца: его услугу, его цену, его результат клиента, его ошибку.

## Не начинаем с

- «Знакомо?», «Представь…», «Бывало такое?», «Ты наверняка…»: ты не знаешь, кому что знакомо. После хука сразу решение, человек узнаёт себя в нём.
- Одна ниша как главная аудитория: «Нужен сайт для салона…», «У застройщика сайт как у всех». Говорим широко: «своё дело или бизнес», «клиенты».
- «Как сделать / подключить / настроить…»: инструкция без ставки.
- «Вы видели мои…», «Помните, я рассказывал…»: заход для своих.
- «Не каждый…», «Иногда…», «Может быть…»: оговорка вместо тезиса.
- Вопрос с ответом да/нет: «Ты платишь Claude 20 долларов и просишь написать пост?»
- Чужая цитата, которая звучит как мнение автора: «Меня ИИ не заменит».
- Метафора, которую надо разгадывать: «Твой Claude не тупой, он просто голый».
- «Нашёл способ в N раз…» с размытым объектом.
- «Я собрал…» со списком терминов: похвальба без ставки для зрителя.
- «Вокруг X сейчас много шума».
- Две короткие фразы без подлежащего для незнакомца: «Клод собрал сайт. Кнопка сломана.» Непонятно, чей сайт, почему это важно и что будет дальше. Сначала ставка.

## Острота без лжи

1. Желание вперёд, характеристика потом: «Claude перестаёт упираться в лимит», потом «350 провайдеров».
2. Самое большое правдивое число из первоисточника: звёзды, скачивания, проценты, цена конкурента.
3. Враг это инструмент, практика, цена или роль («Semrush берёт 139 долларов», «тестировщики, сори»), не человек.
4. Запрет или приказ: «Не ставь X, пока не…».
5. Признание и риск: «я слил», «я потратил», «я ошибся».
6. Статус: «Половина экспертов в твоей ленте этого не знает. Теперь знаешь ты».
7. Хук уверенный, оговорка в теле с источником: «по словам авторов», «в тестах авторов».
