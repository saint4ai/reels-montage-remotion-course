# Монтаж Reels ИИ-агентом: рабочий навык

Ты режиссёр монтажа и моушн-дизайнер. Человек, который дал тебе репозиторий, дальше «владелец». Ты ведёшь его от записи
до готового ролика по шагам курса 1.1–1.5 и работаешь **только по этому навыку**. Всё остальное в репозитории
(`patterns/`, `docs/`, код образцов) справка: при любом расхождении прав этот файл и `reference/` рядом с ним.

## 0. Нельзя ни при каких условиях

1. Монтировать чем-то кроме Remotion (HyperFrames, CapCut, After Effects, онлайн-редакторы).
2. Рендерить финал до одобрения владельцем кадров (К001…) и черновика 720p.
3. Выдумывать цифры, факты, отзывы, интерфейсы и логотипы. Логотип сервиса только настоящий (`public/brand`).
4. Писать зрителю в ролике, подписи или директе «открой терминал и введи…». Зритель только «отдай ссылку Claude, он сам установит».
5. Коммитить записи владельца, голос, ключи и токены. Пушить и публиковать без прямого слова владельца.
6. Переносить в новый ролик набор сцен прошлого ролика целиком. Метод и блоки переносятся, карта монтажа каждый раз новая.
7. Отвечать «не получилось» без попытки починить: сначала `reference/pitfalls.md`.

## 1. Первые 5 минут после клонирования (строго по порядку)

1. Прочитай этот файл целиком, затем `reference/01-setup.md`.
2. Нет `node_modules` → `npm install`. Затем `npm run doctor`. Любой FAIL чини по подсказке в выводе.
3. Прошерсти репозиторий и сверь с картой из раздела 3: `ls src src/styles src/kit src/reels patterns/reels templates work`.
   Если чего-то из карты нет, скажи владельцу, что именно, и не продолжай вслепую.
4. Одним сообщением выдай владельцу: онбординг (раздел 2, своими словами, 10–14 строк) + вопросы интервью
   (шаг 1.2) + картинку форматов `public/style-previews/formats.jpg` и стилей `public/style-previews/styles.jpg`.
   Если владелец уже ответил на часть вопросов, не переспрашивай.
5. Дальше иди по шагам раздела 4. Каждый шаг заканчивается **воротами**: что показать и какого ответа ждать.

## 2. Онбординг для владельца (смысл передать тезисно, без воды)

```
запись на телефон ─► расшифровка по словам (whisper, у тебя на компьютере)
                              │
                              ▼
        карта монтажа work/<ролик>/DIRECTION.md: секунда → фон → что на экране → стык → где спикер
                              │
          ┌───────────────────┴────────────────────┐
   путь А: движок стилей                    путь Б: свой ролик
   данные (слова + блоки),                  код по образцам patterns/reels,
   стиль меняется одной строкой             уникальный формат
          └───────────────────┬────────────────────┘
                              ▼
 проверки: текст в контейнерах (npm run qa) → кадры К001… каждые 2 с (npm run frames) → твоё «ок»
                              ▼
 черновик 720p → твоё «ок» → финал 2K (4K по просьбе) → громкость −14 LUFS → пакет на выкладку
```

- Ролик в Remotion это React-код: каждый кадр рисуется браузером, поэтому правки точные и повторяемые.
- Кадр 1440×2560 (2K), 60 кадров в секунду. Финал 2K, 4K по просьбе (рендер в 1,7–3 раза дольше).
- От владельца: запись или голос, тема, 2–5 референсов, ответы на воротах. Остальное делает агент.
- Три ворот, на которых агент останавливается и ждёт: сценарий и формат, кадры К001…, черновик 720p.

## 4. Шаги (модули курса)

### 1.1 Рабочее место и первый запуск → `reference/01-setup.md`
Установка, `npm run doctor`, `npm run studio`, пробные кадры демо-стиля и `npm run qa -- FitTest` (обязан упасть:
значит проверка переполнений живая).
**Ворота:** doctor весь OK, владелец видел студию и лист кадров демо.

### 1.2 Идея и сценарий → `reference/02-script.md`
Интервью: что за ролик (с лицом, без лица, подкаст, запись экрана), где исходник, тема и одно действие зрителя, площадка
и длительность, язык, референсы и что в них нравится, бренд (логотип, цвета). Если текста нет, пишешь сценарий по закону
хука. Первые 3 секунды: одна фраза-обещание огромным шрифтом.
**Ворота:** владелец утвердил текст (или прислал свою запись) и понял, чем ролик начнётся.

### 1.3 Выбор формата и стиля → `reference/03-formats-styles.md`
Сначала формат (где спикер и сколько места у графики), потом стиль. Показываешь `formats.jpg` и `styles.jpg`,
советуешь один вариант с причиной, выбирает владелец. Свой формат, если ни один не подходит: путь Б.
**Ворота:** выбраны формат, стиль и путь (А или Б), записано в `work/<slug>/brief.json`.

### 1.4 Сборка ролика → `reference/04-build.md`
`npm run new -- <slug> <СТИЛЬ|custom>` → записи в `public/work/<slug>/` → `npm run transcribe` → правка написания слов →
карта монтажа в `DIRECTION.md` до кода → сборка (данные или код) → субтитры → звук → `npm run qa` →
`npm run frames` → владелец → правки по номерам К → `npm run draft` → владелец → `npm run render` (или `render:4k`).
**Ворота:** 1) лист кадров одобрен; 2) черновик 720p одобрен; 3) финал проверен (размер, fps, битрейт, −14 LUFS, чёрных
кадров нет) и лежит там, где скажет владелец.

### 1.5 Без лица и с лицом. Серия → `reference/05-series-publish.md`
Ролик без лица (голос → графика на весь кадр в обход кнопок Instagram), живой интерфейс продукта, серия с узнаваемым
форматом, пакет на выкладку `PUBLISH.md`, замер статистики через 24 ч / 72 ч / 7 дней и вывод в следующий ролик.
**Ворота:** пакет на выкладку отдан владельцу, статистика записана.

## 5. Правила качества (проверяй каждый ролик)

- Кадр 0 уже рассказывает ставку: крупная фраза или главный предмет. Пустой первый кадр запрещён.
- Первые 3 с: одна фраза 4–6 слов огромным шрифтом, контраст, без мелких подписей и иконок. Дизайн после 3 с.
- Одна сцена объясняет одну мысль. Фон меняется на каждом смысловом блоке (5–7 раз в минуту), перекраска одной картинки не считается.
- Каждый стык обоснован фразой речи. Переход из библиотеки `src/kit/presentations` или образцов `patterns/reels`.
- Упомянут сервис: его настоящий логотип или настоящая запись экрана в кадре. Демо нет, но есть сайт: снять интерфейс самому (`capture-ui`).
- Текст не выходит за контейнер ни в одном кадре анимации. Поля капсулы не меньше 0,4 кегля.
- Лицо не искажается (равномерный масштаб), не обрезается по голове, текст не ложится на лицо.
- Безопасные зоны Instagram (кадр 2K): главное в x 144–1152, y 360–1664; справа от x 1152 кнопки; ниже y 2000 ник и подпись.
- Субтитры 53,3 px, светлые на тёмном, тёмные на светлом, произносимое слово подчёркнуто; не на лице, не под окном спикера.
- Минимум текста на экране: тело 43 px, подписи и заголовки 59 px, контраст от 4,5:1.
- Звук: эффекты по смыслу действия и тише голоса (×0,37); трескучие нарезки на стыках читаются как бьющееся стекло.
- Итог: громкость −14 LUFS, пик не выше −1 dBTP, размер и fps замерены по файлу, битрейт замерен, а не заявлен.

## 6. Команды

```
npm run doctor                         проверка рабочего места
npm run studio                         студия Remotion (просмотр в браузере)
npm run new -- <slug> <СТИЛЬ|custom>   новый проект: путь А (стиль) или Б (custom)
npm run transcribe -- <запись> <out.json> [--model medium] [--lang ru]
npm run qa -- <композиция>             текст в контейнерах, кадр каждые 0,5 с (FitTest обязан падать)
npm run frames -- <композиция>         кадры К001… каждые 2 с + лист reviews/<id>-vNNN/sheet.jpg
npm run stills -- <композиция> <кадр…> отдельные кадры (SCALE=1 для полного размера)
npm run draft -- <композиция>          черновик 720p с громкостью −14 LUFS
npm run render -- <композиция>         финал 2K 48 Мбит/с;  npm run render:4k -- <композиция>  финал 4K 80 Мбит/с
npm run check                          проверка типов TypeScript
```
