# 1.3 Формат и стиль

Сначала **формат** (где спикер и сколько места у графики), потом **стиль** (визуальный язык). Показать владельцу
`public/style-previews/formats.jpg` и `styles.jpg`, посоветовать один вариант с причиной, выбирает владелец.

## Форматы (кадр 1440×2560)

| Формат | Раскладка | Когда | Образец |
|---|---|---|---|
| **Половина экрана** | спикер снизу 1440×1280 с y 1280, графика сверху, шов линией; субтитры над швом, centerY 1157 | эксперт говорит в камеру про продукт, шаги, инструменты. Самый проверенный: на нём рилс 107 тыс. просмотров | `EXPERT`, `APPLE` (путь А), `patterns/reels/r27-connectors-half` |
| **Половина + окно в углу** | по умолчанию половина; на схеме или живом интерфейсе спикер сворачивается в окно 500×450 (x 70, y 1548), графика на весь кадр, потом обратно | экспертный ролик, где 2–3 блока требуют всей площади | шаблон `src/reels/_template`, `patterns/reels/r29-jarvis-ironman` |
| **Карточка спикера** | спикер в скруглённой карточке 1080×1380, обрезан сверху и снизу, фон вокруг живой; вставка референса 30% ширины слева; туториал в корпусе 79% высоты по центру | туториал «как сделать» с записью экрана | `patterns/reels/r28-trend-apple` |
| **Спикер внизу, графика сверху** | карточка по центру внизу трёх размеров: компактная 648×613 (много предметов), базовая 864×819, широкая 1011×957 (одна строка текста); переход 0,5–0,7 с на смене смыслового блока | схемы и холст с камерой | `GLASS`, `PRISM`, `patterns/reels/r19-direct-assistant` |
| **Без лица, на весь кадр** | только голос; графика сверху донизу в обход кнопок справа и ника внизу; субтитры centerY 1467 | озвучка без съёмки лица, обзоры сервисов | `PULSE`, `patterns/reels/r26-search-console` |
| **Подкаст** | кадр подкаста снизу, доска с маркером сверху | нарезки интервью | `PODCAST` |

Лицо в любом окне: равномерный масштаб, точка лица в кадре записи (например x 0,5, y 0,42) ставится в нужное место окна;
голова целиком, не сплющивать. Окно в углу только слева: справа кнопки Instagram.

## Стили пути А (движок, стиль меняется одной строкой)

| Стиль | Язык | Когда |
|---|---|---|
| PRISM | светлая платина, стеклянная капсула пружиной раскрывается в карточку-интерфейс | сервисы, автоматизации, продукт |
| ORBIT | космос, предметы и логотипы на трёх слоях глубины плывут без остановки | системы, связи, технологии |
| TRACE | тетрадь в клетку, ручка дорисовывает подчёркивания, галочки и связи | обучение, чек-листы, разборы |
| PULSE | круг-рассказчик пульсирует в такт речи, крупные предметы | без лица, энергичный голос |
| GLASS | платина, матовое стекло, квадрат спикера, рукописные пометки | экспертные разборы, продажи |
| PORTRAIT | квадрат спикера переезжает по нижнему коридору, тёмные и светлые сцены | личный рассказ |
| APPLE | спикер на нижней половине, сверху тёмная сцена с прожектором | технологии, запуски |
| PODCAST | подкаст снизу, доска с маркером сверху | интервью |
| EXPERT | спикер на нижней половине, сверху платиновая доска: заголовок с полосой, карточки, снимки сервисов в окне браузера | экспертный рассказ про сервисы |

Данные одинаковые для всех: блоки `hook`, `list`, `stat`, `logos`, `flow`, `cta` (типы в `src/template/blocks.tsx`).
Сменить стиль = поменять `style` у проекта в `src/projects/index.ts`.

## Свои форматы пути Б (образцы с кодом и картой монтажа в `patterns/reels/`)

| Образец | Что в нём | Оценка автора курса |
|---|---|---|
| `r19-direct-assistant` | сцены + холст с камерой, 3D-иллюминатор, наклейки, тогл | «охуительный монтаж» |
| `r20-techno-poster` | огромная типографика, штрихкоды, стеклянный 3D-предмет поверх букв | утверждён как стиль |
| `r21-liquid-glass` | жидкое стекло с преломлением, прожекторы, капсулы | утверждён |
| `r22-live-canvas` | живая сборка: курсор агента кликает, чек-лист, дорожка модулей | принят |
| `r25-opus55-games` | на каждую сцену свой космический фон, карточки игр | «космос на каждую сцену понравился» |
| `r26-search-console` | без лица на весь кадр: орбитальный холст + сцены | пролистали 74% в первые 3 с: хук слабый, учесть |
| `r27-connectors-half` | половина экрана, PRISM в индиго и оранжевом | пролистали 49% против 34% у оригинала: мелкий текст в хуке |
| `r28-trend-apple` | белый холст, плывущие волны, карточка спикера, вставка слева, туториал в корпусе | «монтаж просто охуенный» |
| `r29-jarvis-ironman` | HUD Железного человека: реактор по голосу, половина + окно в углу, живой интерфейс продукта | «классно сделал» |

Правило: из образца берётся **метод и блоки**, а карта монтажа (главный предмет хука, форма схемы, вставки, стыки, цвета
зон) каждый раз новая под текст. Сцены прошлого ролика целиком не переносить.

## Выбор пути

- Путь А, если ролик ложится на блоки hook, list, stat, logos, flow, cta и владельцу подходит стиль из девяти. Быстро.
- Путь Б, если нужен свой формат, живые записи экрана с наездами, реактор, туториал в корпусе, уникальный хук.
  Начинать с шаблона `custom` и ближайшего образца.
