# Грабли и лечение (каждая уже стоила пересборки)

| Симптом | Причина | Лечение |
|---|---|---|
| Видео или скриншот при наезде сжался по ширине, лицо в маленьком окне сплющено | Tailwind ставит `img, video { max-width: 100% }` | у `<Img>`/`<Video>` шире окна: `maxWidth: 'none', maxHeight: 'none'` |
| Пустой или тёмный первый кадр | элементы хука въезжают с нуля | хук виден с кадра 0: вход с отрицательным временем или сразу на месте |
| На смене строки субтитров мигает пустая капсула | текст ждёт, пока капсула дорастёт | общий `Captions`: капсула сразу берёт ширину новой строки, текст с первого кадра |
| Текст вылез за капсулу или карточку | ширина задана числом, шрифт ещё не загрузился | мерить после загрузки шрифтов; контейнер растёт под текст; `npm run qa` |
| Чёрный логотип не виден на тёмном фоне | одноцветный SVG рисуется чёрным | красить маской: `background: цвет; mask-image: url(лого)`; фирменный цвет сервиса или белый |
| На стыке звук как бьющееся стекло | трескучая нарезка (дрожание, блюр, трансформация) | на стыки вуши; клики и поп на появления; проверить характер нарезки |
| Черновик рендерится часами | браузер рисует WebGL программно (нет видеокарты или она слабая) | 2 потока, 720p для проверки, 4K только в финале; 3D только где нужно |
| `npm install` падает с ERESOLVE | пакеты 3D ждут другую версию React | в репозитории `.npmrc` с `legacy-peer-deps=true`, не удалять |
| Рендер падает по таймауту на кадре с видео | долгая перемотка тяжёлого файла | перекодировать запись в H.264 (`reference/01-setup.md`), таймаут уже 120 с |
| Шаги на экране не совпадают с речью | запись экрана идёт в своём темпе | перемонтировать запись по опорным словам: кусочная скорость ffmpeg |
| Лицо обрезано по голове в окне | кадрирование по центру, а лицо выше | точка лица (`FACE`, `headY`) и окно шире; голова и плечи целиком |
| Первые кадры записи экрана показывают лишнее (лицо, обои) | начало файла | `trimBefore` или обрезка краёв ffmpeg `crop` |
| Цифра стоит «0» до начала счёта | счётчик виден раньше старта | показывать число с момента `countAt` |
| Объект пролетает через другие | прямой маршрут | маршрут кривой в обход, 8 кадров на пролёт проверить `npm run stills` |
| Хвосты прошлой сцены видны после стыка | сцена не гаснет полностью | прозрачность прошлой сцены до 0 к концу перехода |
| Тексты для людей звучат как ИИ | длинные тире и штампы | точка, запятая, двоеточие; без «не просто…, а…» |
| Финал «в 4K» мутный | исходник спикера 1440 растянут до 2160 | для 4K перекодировать запись в 2160×3840 и снимать интерфейсы с плотностью 1,5 |
| Облако «загрузило», а файла нет | копия ещё синхронизируется | сверить размер и контрольную сумму, дождаться статуса облака |
| Рендер падает по таймауту декодера на клипе 1080p 60 к/с | `Video` из `@remotion/media` не успевает декодировать тяжёлый клип | для клипов 1080p и выше брать `OffthreadVideo` (в `Clips` набора `expertBoardKit` так уже сделано), `Video` оставлять для лёгких записей |
| Станции ЛИНЗЫ копятся у субтитров и полосы спикера | соседние станции холста попадают в нижнюю часть кадра и ложатся на текст | маска над станциями: `linear-gradient(180deg, #000 0, #000 1360px, transparent 1470px)` (уже в `LensReel`, `src/reels/rm/lensLow.tsx`); пунктиры и пятна гасить по `until` |
| Широкие низкие рамки камеры режут голову | рамка закрывается записью по ширине, голова не помещается: виден лоб и глаза | рамка не ниже 0,8 ширины: кружок или карточка Screen Studio (`camGuard` в `src/kit/speakercam.tsx`); кадр каждого ключа камеры смотреть в полный размер, на листе 0,25 срез не виден |
| Углы полосы спикера и края карточек не видны на телефоне | Instagram растягивает 9:16 по высоте экрана и срезает бока (68 px на вкладке Reels, 130 px во весь экран) | полоса уже кадра на 130 px с каждого бока, радиус 110, графика и субтитры в x 160…1280; кадр смотреть в трёх видах (`patterns/techniques/instagram-viewport-guard.md`) |
| Компьютер виснет во время рендера | несколько тяжёлых процессов сразу: рендер, кодирование ffmpeg, стоп-кадры и студия Chrome | один тяжёлый процесс за раз; рендер с `--concurrency=2`, кодирование `-threads 4`, лишние окна студии закрыть |
| Подложка субтитров прыгает на каждом четвёртом кадре | ширина строки измерена запасным шрифтом, пока нужное начертание не загрузилось | `src/montage/Captions.tsx` и `useFontsReady` ждут именно нужный вес и меряют строку на каждом кадре; не подменять их самодельными |
